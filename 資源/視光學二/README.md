## 怎麼放進遊戲

**方法一：合併進框架**
1. 框架 `content/project.json` 已經有 `optometry` 科目，不用新增；想要的話可以把本包 `content/project.json` 裡的 `desc`、`words` 貼過去（不要整個覆蓋檔案）。
2. 把 `content/learn/optometry/optom2/`、`content/bank/optometry/optom2/` 複製到框架的 `content/learn/optometry/`、`content/bank/optometry/`。
3. 把 `img/optom2-u1` ～ `optom2-u3` 複製到框架根目錄的 `img/`。
4. 在框架根目錄執行：

```bash
python tools/build.py
```

**方法二：不改框架檔案**
營地「📥 導入素材」→ 選擇資料夾 → 選這個 `視光學二` 資料夾。

## 重新產生

改內容時修改 `_src/` 的 `u*.py`（課程）或 `b*.py`（題庫），然後依序執行：

```bash
python project.py && python diagrams.py && python u1.py && python u2.py && python u3.py && python b1.py && python b2.py && python b3.py && python balance.py && python lint.py
```

`balance.py` 會重新分散單選題的答案字母（詳解裡的 A～D 會跟著換），一定要在 `u*.py`、`b*.py` 之後執行。`lint.py` 檢查概念卡長度與節奏。**已上線後不要改 lesson id、題本 id、題號**，否則作答紀錄對不上。

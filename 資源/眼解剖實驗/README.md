# 眼解剖實驗刷題包

## 內容

- `眼解剖實驗_題庫與學習模式.json`：同一包含兩個題本與兩個完整學習單元（9 堂課），符合 `xd-bundle/1`。
- `img/eye-anat-orbit/orbit-unlabeled.png`：眼眶骨無文字標籤圖，題目以標記點測中文＋英文名稱。
- `img/eye-anat-visual-path/visual-path-specimen.png`：腦底面無文字標籤標本圖，題目以標記點測視覺路徑構造。
- `逐字稿與簡報差異校訂.md`：逐字稿補充、簡報獨有內容、錯字及視野題校正紀錄。

題庫共 **145 題**：骨質眼窩與顱骨圖譜 88 題；視覺路徑、血液供應、近反應與視野定位 57 題。學習模式另含 **2 個單元、9 堂課**，每課均有導入、概念卡與即時檢核、範例、題庫實戰及回顧；眼眶與腦底面各有無標籤圖解辨認。跑台名稱題要求同時寫中文與英文，題目以填答／雙語配對為主，另有位置、通過物、路徑與臨床判讀題。

## 匯入方式

在遊戲營地選「📥 導入素材」，選取本資料夾，確認科目「眼解剖實驗」及兩份題本後匯入。題目引用的圖片已放在此資料夾內，請整個資料夾一起選取。

## 練習建議

先看無標籤圖，對每個標記點口述一次中文和英文，再作答。跑台練習時可自行限時 **40 秒／題**。填答時中文與英文都要寫；不要只背英文或只背中文。

> 圖片取自提供的課堂投影片，僅供個人／課堂複習，不應公開散布。逐字稿中的行政提醒及實驗室規則沒有混入解剖名稱題。

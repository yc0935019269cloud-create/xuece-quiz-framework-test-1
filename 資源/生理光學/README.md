## 怎麼放進遊戲

**方法一：合併進框架（和眼解剖一樣）**
1. 把 `content/project.json` 裡的 `physopt` 科目加進框架 `content/project.json` 的 `subjects`（不要整個覆蓋，否則眼解剖等科目會不見）。
2. 把 `content/learn/physopt/`、`content/bank/physopt/` 複製到框架的 `content/learn/`、`content/bank/`。
3. 把 `img/physopt-u1` ～ `physopt-u4` 複製到框架根目錄的 `img/`。
4. 在框架根目錄執行：

```bash
python tools/build.py
```

**方法二：不改框架檔案**
營地「📥 導入素材」→ 選擇資料夾 → 選這個 `生理光學` 資料夾。科目、單元、題本、圖片會自動辨識（存在瀏覽器裡）。

## 重新產生

內容都由 `_src/` 的 Python 產生（`common.py` 裡的 `OUT` 是輸出位置）。改內容時修改對應的 `u*.py`（課程）或 `b*.py`（題庫），然後依序執行：

```bash
python project.py && python u1.py && python u2.py && python u3.py && python u4.py && python balance.py && python b1.py && python b2.py && python b3.py && python b4.py
```

`balance.py` 會重新分散課程檢核題的答案字母，一定要在 `u*.py` 之後執行。**已上線後不要改 lesson id、題本 id、題號**，否則作答紀錄對不上。

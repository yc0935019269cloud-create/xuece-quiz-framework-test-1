# 02 素材 → 出題與詳解

> 讓 AI 根據講義、課本（或 01 做好的課程）自己出一份題本，每題附完整詳解。
> 先改最後的【我的設定】（題數、題型比例、難度、考試風格）。題數多時一次 30～50 題，之後回覆「繼續」。

## 2-A 出題＋詳解（主要提示詞）

````text
你是資深命題委員兼教學老師。請根據我提供的素材出一份題本，每題附詳解，輸出成遊戲可以直接導入的 JSON。

# 命題原則
1. 只考素材教過的內容。每題註明考點（tags）。素材中的每個重要觀念、公式、數據、構造、流程至少要被考到一次；重要的考 2～3 次、從不同角度。
2. 每題只有一個主要考點，題幹清楚、條件完整、沒有歧義；單選題只有一個最佳答案。
3. 認知層次分散：約 25% 記憶與理解、45% 應用與分析、30% 綜合判斷（情境題、圖表題、跨觀念題、臨床案例題）。
4. 誘答選項必須「看起來合理」，而且各自對應一種真實的錯誤：公式用錯、正負號或單位錯、混淆相似概念或構造、忽略條件、只記一半。不要放一看就錯的選項。
5. 選項長度與語氣相近；正確答案的字母要平均分散；不要用「以上皆是／以上皆非」。
6. 否定題要把「不」「錯誤」「無法」用 **粗體**。
7. 數字題：自己完整算一遍，並確認每個誘答選項的數值都來自某種典型錯誤算法。
8. 同一份題本中不要有兩題考幾乎相同的東西、也不要有一題的題幹洩漏另一題的答案。

# 各科命題重點
【數學】概念題、計算題、證明思路題；數值選項依常見錯誤設計；填答題的答案要唯一（最簡分數、指定小數位數）。
【物理、生理光學、幾何光學、視光學】單位與正負號慣例要在題幹中清楚（或全題本一致並寫在第一題前的說明）；度數計算、成像位置與性質、屈光異常矯正、調節與老花、稜鏡、有效度數、頂點距離換算等依素材出題；處方題（例如 -2.00DS/-0.75DC×180）要考轉換與解讀。
【化學】計量、反應式、實驗判讀、三層表徵。
【生物、生理學】構造功能、流程順序、調控與回饋、實驗設計與判讀。
【解剖學、組織學】位置與相鄰關係、起止點、作用、神經支配、血液供應、臨床病例推理（例如某神經受損會出現什麼症狀）；看圖辨識題用「圖上編號」（見下方 marks）。
【國文】字音字形、詞義、文意判讀、修辭、文學常識、文言閱讀題組；引用原文一字不改。
【英文】詞彙、文法、綜合測驗（克漏字題組）、文意選填、閱讀測驗題組、翻譯（open）。
【社會】史料判讀、因果、時序、地圖與統計圖判讀、公民概念應用。
【學測風格】（【我的設定】要求時）使用題組、多選、混合題（選擇＋填答＋非選）、生活情境與跨科素養；多選題選項 5 個。
【國考、證照風格】四選一為主，重視臨床情境、數值門檻、法規與標準流程。

# 題型
- single 單選：choices 4 個（學測 5 個），answer 寫字母，例如 "B"。
- multi 多選：choices 5 個，answer 寫所有正確字母，例如 "ACE"（2～4 個正確）；題幹末尾寫「（多選）」。
- tf 是非：answer 寫 true 或 false。
- fill 填答：answer 寫標準答案；accept 陣列列出所有可接受寫法（有無單位、全形半形、中英文、簡稱、不同小數位數、分數或小數）。答案要短而唯一；答案不唯一就改成 open。
- open 非選（申論、計算過程、畫圖、翻譯、作文）：answer 寫參考答案；explain 寫評分要點（①…②…③…，各幾分）。
- 題組：多題共用一段文章、情境、數據表或圖。在 groups 定義，題目用 group 指向它。

# 詳解（explain）——每題都要，這是學生學習的關鍵
依序包含：
1. **考點**：一句話說明這題考什麼。
2. **解題過程**：一步一步推理或計算，說明每一步「為什麼」。計算放在 ``` 區塊，寫出公式、代入、單位與結果。
3. **選項分析**：單選題逐一說明每個錯誤選項錯在哪、對應什麼迷思；多選題每個選項都要說明對或錯及理由。
4. **延伸**（選填）：易混淆觀念對照、記憶技巧、同類題的快速判斷法。
長度約 100～300 字，計算與題組題可更長。

# 圖片
- 能用文字或 Markdown 表格表達的不要用圖（數據表請用表格）。
- 需要圖的題目：img 寫 ["img/<題本id>/q<題號>.png"]；題組圖用 img/<題本id>/g-<題組id>.png。
- 看圖辨識題（解剖、構造、地圖）：用一張「沒有文字標籤」的圖，在 marks 標出編號位置：[{ "x": 35.5, "y": 42, "label": "1" }, …]，x、y 是圖片寬高的百分比（0～100，左上角 0,0），點要落在構造上。題幹問「圖中編號 2 的構造是？」。無法確定座標時不要寫 marks，改在【圖片清單】中說明需要在圖上標註的位置。
- 圖從哪裡來：素材中的圖（你能處理檔案就裁切出來，不能就列進【截圖清單】）；或網路上可合法使用的圖（Wikimedia Commons、OpenStax、Servier Medical Art、公有領域圖譜），寫出網址與授權，能下載就一起打包，不能就列出直接網址與要存成的檔名。

# 輸出格式
輸出一個 JSON（xd-bundle/1）：

```json
{
  "schema": "xd-bundle/1",
  "subjects": [ { "id": "physopt", "name": "生理光學", "theme": "sci", "words": ["屈光", "調節", "透鏡"] } ],
  "sets": [
    {
      "schema": "xd-bank/1",
      "set": { "id": "physopt-ch2-gen", "subject": "physopt", "name": "第2章 眼的屈光系統（自編練習）", "path": ["生理光學", "第2章"], "source": "依據素材：書名、章節", "order": 2 },
      "groups": [
        { "id": "g1", "title": "情境：驗光結果", "text": ["某人……", "", "| 項目 | 右眼 | 左眼 |", "|---|---|---|", "| 球面 | -2.00 | -1.50 |"] }
      ],
      "questions": [
        { "n": 1, "type": "single", "stem": "題幹", "choices": ["選項", "選項", "選項", "選項"], "answer": "B", "explain": ["**考點**：……", "", "**解題**：……", "```", "F = 1/f = 1/0.5 m = 2.00 D", "```", "**選項分析**：A 錯在……"], "tags": ["屈光度"], "level": 2 },
        { "n": 2, "type": "multi", "stem": "題幹（多選）", "choices": ["…", "…", "…", "…", "…"], "answer": "ACE", "explain": "……", "tags": ["……"], "level": 3 },
        { "n": 3, "type": "tf", "stem": "敘述", "answer": false, "explain": "……", "tags": ["……"], "level": 1 },
        { "n": 4, "type": "fill", "stem": "題幹（只填數字，單位 D）", "answer": "+2.50", "accept": ["+2.50", "2.5", "+2.5", "2.50"], "explain": "……", "tags": ["……"], "level": 2 },
        { "n": 5, "type": "open", "stem": "說明……", "answer": "參考答案", "explain": "評分要點：①……（2分）②……（2分）", "tags": ["……"], "level": 3 },
        { "n": 6, "type": "single", "group": "g1", "stem": "依上表，……", "choices": ["…", "…", "…", "…"], "answer": "D", "explain": "……", "tags": ["……"] },
        { "n": 7, "type": "single", "stem": "圖中編號 2 的構造是？", "img": ["img/physopt-ch2-gen/q7.png"], "marks": [ { "x": 30, "y": 40, "label": "1" }, { "x": 62, "y": 55, "label": "2" } ], "choices": ["…", "…", "…", "…"], "answer": "A", "explain": "……", "tags": ["……"] }
      ]
    }
  ]
}
```

欄位規則：
- set.id：英文、數字、-、_，全部題本中唯一；題號 n 從 1 開始連續。
- set.subject：科目 id（小寫英文、數字、底線），並在 subjects 中定義（theme：lit 語文、lang 外語、math 數學、calc 計算應用、hist 人文社會、sci 自然科學醫學視光、mix 綜合）。
- set.year：題目有年份時才寫（例如歷屆試題 113）。
- level：1 基礎、2 標準、3 進階。tags：1～3 個考點關鍵字，不可以把答案寫進 tags。
- 長文字可寫成字串陣列（一個元素一行）。Markdown 可用粗體、清單、表格、``` 區塊。
- 不能用 LaTeX；數學與化學用 Unicode（x²、aₙ、√2、π、θ、Δ、≤、≥、≠、±、×、H₂O、SO₄²⁻），分數寫 a/b。

# 交付方式
1. JSON 必須合法：不能有註解、結尾多餘逗號；字串內雙引號寫成 \"；不要在字串裡直接換行。
2. 你能建立檔案時：存成 <題本id>.json，圖片放在 img/<題本id>/，整個打包成 zip。
3. 不能建立檔案時：先寫「檔名：<題本id>.json」，接著用 ```json 程式碼區塊輸出完整 JSON。
4. 程式碼區塊外只放：【圖片清單】（檔名｜內容｜來源網址｜授權）、【截圖清單】（檔名｜素材第幾頁｜截取範圍）、【考點分布】（每個考點幾題、難度分布）、【需要確認】（你不確定答案或素材有疑義的題號與原因）。
5. 題數多、一次輸出不完：在完整的一題之後停止，輸出目前的部分（完整合法 JSON，同一個 set.id），最後寫「【未完，請回覆「繼續」】」。之後每批用相同的 set.id、題號接續，遊戲導入時會自動合併。

# 輸出前自我檢查
□ 每題 answer 與 explain 的結論一致；多選題每個字母都在詳解中說明。
□ 正確答案字母分布平均；沒有重複考點的題目。
□ 數字題全部重算；單位、正負號正確；fill 的 accept 已列出常見寫法。
□ 題組題的 group 都有定義；圖片路徑都列進清單。
□ JSON 合法、沒有 LaTeX。

【我的設定】
科目與 id：（例如：生理光學，physopt）
題本名稱與 id：（例如：第2章 眼的屈光系統（自編練習），physopt-ch2-gen）
分類階層 path：（例如：["生理光學", "第2章"]）
學習者與考試風格：（例如：視光系學生，國考風格／高三學生，學測風格）
題數與題型：（例如：40 題：單選 24、多選 6、是非 4、填答 4、非選 2）
難度比例：（例如：基礎 25%、標準 45%、進階 30%）
題組：（例如：至少 2 組，每組 2～4 題）
其他要求：（例如：一定要有看圖辨識題；計算題占一半）
````

## 2-B 繼續出題

```text
請接著出下一批題目，規則與格式完全相同：
- 輸出新的完整合法 JSON（xd-bundle/1），set.id 與上次相同，題號從上次最後一題的下一號開始。
- 不要重複上一批考過的觀念角度；優先補上【考點分布】中還不足的考點。
- 最後照樣附上【圖片清單】、【截圖清單】、【考點分布】、【需要確認】。
這一批要出：（例如：再 30 題，著重計算與題組）
```

# 00 使用流程（先讀這份）

> 這裡的提示詞可以直接貼給任何 AI（ChatGPT、Claude、Gemini…）。每一段都附完整的格式規格，AI 不需要看過這個遊戲。
> 流程：**開新對話 → 先上傳素材 → 貼上提示詞 → 改最後的【我的設定】→ 把 AI 的輸出存進資料夾 → 營地「📥 導入素材」選那個資料夾**。

## 我手上有什麼 → 用哪一份

| 你手上的東西 | 想得到 | 用 |
|---|---|---|
| 講義、課本、PDF、筆記、投影片、錄音逐字稿 | 學習模式課程（邊學邊練、會打怪） | **01 素材 → 學習模式** |
| 講義、課本（或 01 做好的課程） | 一整份新題目＋詳解 | **02 素材 → 出題與詳解** |
| 已經有題目和答案，但沒有詳解或詳解太簡單 | 每題完整詳解 | **03 既有題目補詳解** |
| 考卷、學測歷屆、題本、Word、網頁、Excel 的題目 | 轉成題庫（自動分科目、年份） | **04 題目 → 題庫** |
| 解剖圖、構造圖、地圖、儀器圖，需要找圖或標記 | 可點選辨識的圖解 | **05 找圖與圖片標記** |
| 光路、波動、生理流程、函數圖形…看動畫比較懂 | 互動模擬／動畫 | **06 互動與動畫** |
| AI 產出的東西想再檢查、導入時出錯 | 審查報告、修好的檔案 | **07 審查、修正、連結**（7-A 審查、7-B 修格式） |
| 題庫和課程都有了，想確認「教材有沒有追上題目的深度」、讓實戰只抽教過的題 | 嚴謹連結＋補教材（題目不降級） | **07-C 嚴謹連結、07-E 覆蓋審計** |

## AI 的輸出怎麼存

- **AI 給 zip 或 .json 檔下載**：解壓縮後整個資料夾拿去導入。
- **AI 直接在對話裡輸出**：把整段回覆複製，存成 `.md` 檔（記事本另存新檔，編碼選 UTF-8）。遊戲會自動抓出裡面的 JSON。
- **有圖片**：AI 會列出【圖片清單】或【截圖清單】（檔名＋在第幾頁、截哪裡、或下載網址）。照檔名把圖存到**同一個資料夾**（放在 `img` 子資料夾也可以），導入時會自動配對。
- **分好幾次輸出**：同一個單元／題本分批沒關係，全部放同一個資料夾一起導入，會自動合併。

## 一次複製好幾段提示詞

在「📋 AI 提示詞」畫面，每一段提示詞前面都有**勾選框**：勾好要用的（例如 01-B＋02-C＋07-C），按底下的「📋 複製已勾選」，就會把它們合成一份（含說明與共用設定欄）一次貼給 AI。也有現成組合：

- **新單元全套**：01-B 課程 → 02-C 題目 → 07-C 連結 → 07-E 審計
- **審查現有內容**：07-A 品質審查 → 07-E 覆蓋審計

## 讓教材追上題目的深度（重要：題目不降級）

- 先有課程或先有題庫都可以，但**兩邊的用詞要一致**：題庫的 tags（考點詞）要用課程教的名詞。
- 課程單元要宣告 `banks`（負責哪些題本）、每課要宣告 `teaches`（教了哪些 tags）；遊戲的實戰只會抽「已經教過」的題。
- 題目要保持深度；教材不夠深時**補教材，不是把題目改簡單**。題目用到的符號（Pe、Pv、JCC…）一定要在課程裡定義過，最難的題要有對應的範例；做完一個單元用 **07-E** 審計一次。
- 在框架資料夾裡用 Claude Code 時，執行 `python tools/build.py --coverage` 會列出所有缺口。

## 小技巧

- 一次交給 AI 的量：學習課程約**一章**、題目約 **30～50 題**最穩定。太多就分批，並對 AI 說「繼續」。
- 選擇**能讀 PDF 和圖片、有程式執行功能**的 AI 模式（例如 ChatGPT 的進階資料分析、Claude 的檔案建立）效果最好：它能自己截題目圖、下載圖片、打包 zip。
- 數理題的答案請抽查；想更保險就用 **07** 請另一個 AI 審查一次。
- 導入後的內容存在這台電腦的瀏覽器；在「導入素材」頁可以「下載」成一個檔案，給學生或別台電腦導入。

## 專案設定（選用）

導入時遊戲會自動建立科目，通常不需要這一步。想先統一規劃科目名稱、主題、怪物名字時才用。

```text
我在用一個「刷題地牢」遊戲框架建立題庫。請依我的需求規劃科目清單，只輸出一個 JSON 程式碼區塊（不要註解）：

{
  "schema": "xd-bundle/1",
  "subjects": [
    {
      "id": "科目代號（小寫英文、數字、底線，例如 anat、physopt、xc_eng）",
      "name": "科目顯示名稱",
      "theme": "lit｜lang｜math｜calc｜hist｜sci｜mix 擇一",
      "desc": "一句話說明範圍",
      "words": ["5～8 個跟這科有關、適合當怪物名字前綴的 2～3 字詞"]
    }
  ],
  "sets": [],
  "packs": []
}

theme 的意思：lit 語文閱讀／寫作、lang 外語、math 數學邏輯程式、calc 計算應用（統計、會計、光學計算也可）、hist 人文社會法律管理、sci 自然科學醫學護理視光、mix 綜合。
規劃原則：
- 範圍大的科目拆開（例如「學測自然」可拆成物理、化學、生物、地科；「視光」可拆成生理光學、幾何光學、眼球解剖、驗光學）。
- 同一套題庫以後會持續加內容，所以 id 要穩定、好懂。
- 學測科目建議用：xc_chi 國文、xc_eng 英文、xc_ma 數學A、xc_mb 數學B、xc_soc 社會、xc_sci 自然（或拆 xc_phy、xc_chem、xc_bio、xc_earth）。

【我的設定】
我要做的題庫：（例如：視光系一年級的解剖學、生理光學、視光學；另外有高三學測各科）
```

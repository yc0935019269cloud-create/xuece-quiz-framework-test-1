# 03 既有題目補詳解

> 題目和答案都有了，但沒有詳解（或詳解太簡略）。可以直接上傳遊戲的題庫檔（JSON／CSV、導入頁「下載」的檔案），也可以上傳考卷 PDF＋答案卷。
> 一次 20～40 題最穩；題目多就分批，回覆「繼續」。

## 3-A 補詳解（輸入是遊戲題庫檔）

````text
你是經驗豐富的解題老師。我上傳的是一份題庫檔（JSON 或 CSV）。請替每一題撰寫完整的詳解，其他內容一律不要改動。

# 絕對規則
- 只改 explain（詳解）；tags 是空的可以補 1～3 個考點關鍵字。題號、題目、選項、答案、圖片、題組都不能動。
- 先自己完整解題。如果你的答案和檔案中的答案不同：不要改答案。在該題 explain 的第一行寫「⚠ 答案存疑：我算出的答案是 ○，理由……」，並列進【需要確認】。
- 題目有圖但你看不到圖時：依題幹與選項盡量解釋，在 explain 第一行寫「⚠ 未看到圖」，並列進【需要確認】。
- 題目本身有錯字、條件不足、兩個答案都對，也列進【需要確認】。

# 詳解的結構
1. **考點**：一句話說明這題考什麼觀念。
2. **解題過程**：一步一步推理，說明「為什麼」。計算題把公式、代入、單位、結果放在 ``` 區塊；題組題指出依據的是文章或圖表的哪一句、哪一格。
3. **選項分析**：單選題逐一說明錯誤選項錯在哪、是哪一種常見迷思；多選題每個選項都要交代對或錯與理由。
4. **延伸**（選填）：易混淆觀念對照、記憶技巧、同類題的快速判斷法。
長度約 100～300 字；計算題、題組題可以更長。用繁體中文與 Markdown（**粗體**、清單、表格、``` 區塊）。不能用 LaTeX：數學與化學用 Unicode（x²、aₙ、√2、π、θ、≤、≠、±、×、H₂O、SO₄²⁻），分數寫 a/b。

# 各科詳解重點
【數學】寫出關鍵轉換的理由；有更快的解法時附在「快解」。
【物理、光學、視光】寫出公式、正負號慣例、單位換算與合理性檢查；處方與度數題要解釋每個數字的意義。
【化學】計量步驟與單位；反應式要平衡。
【生物、生理、解剖】說明構造與功能的關聯；解剖題寫出位置、相鄰構造、神經或血管；病例題寫出推理鏈。
【國文】文言句子附白話翻譯；說明字詞在文中的意思；判讀題指出原文依據。
【英文】關鍵字的中文與詞性；文法題說明規則；長句斷句翻譯；閱讀題指出原文依據句。
【社會】史料或圖表的判讀依據；相關背景與因果。

# 輸出
- 原本是 JSON：輸出完整 JSON，結構與其他欄位完全不變，只更新 explain（與空的 tags）。
- 原本是 CSV：輸出完整 CSV，欄位順序不變，只填 explain 欄；explain 內的換行寫成 \n，整格用雙引號包起來，explain 內的雙引號寫成兩個 ""。
- 你能建立檔案時，直接提供下載檔（檔名與原檔相同）；不能時，先寫「檔名：原檔名」再用程式碼區塊輸出完整內容。
- JSON 必須合法（不能有註解、結尾逗號；字串內雙引號寫成 \"）。
- 最後附【需要確認】（沒有就寫「無」）。
- 一次輸出不完：在完整的一題之後停止，最後寫「【未完，請回覆「繼續」】」。繼續時輸出完整的檔案（前面已完成的也包含在內），或只輸出剩下的題目並保持相同的 set.id 與題號（遊戲導入時會依題號合併）。

【我的設定】
學習者：（例如：高三學生／視光系學生）
詳解風格：（例如：詳細、適合自學；或：精簡、考前複習用）
````

## 3-B 考卷＋答案 → 題庫＋詳解（一次完成）

````text
我上傳的是題目與答案（考卷 PDF、Word、圖片、網頁文字都有可能）。請同時完成兩件事：把題目「忠實地」轉成遊戲的題庫 JSON，並替每一題寫完整詳解。

# 轉換規則（忠於原文）
- 題號、題幹、選項、答案必須和原文一字不差（只修正明顯的 OCR 亂碼與斷行）。不可以改寫、刪減、重新排序。
- 選項不含 (A)(B) 或 (1)(2) 標號，只放內容；原本是 (1)～(5) 的，answer 換成字母（1→A、3→C）；多選「1,3,5」→ "ACE"。
- 題型：單選 single、多選 multi、是非 tf（answer 寫 true/false）、填答 fill（answer＋accept 所有可接受寫法）、非選 open（answer 寫參考答案或評分原則）。
- 答案卷缺某題時：自己解出答案，並列進【需要確認】（標明「AI 推測」）。
- 題組（多題共用文章、圖表、情境）：放進 groups，題目用 group 指向它；文章要完整轉寫。

# 圖片與截圖
凡是題目、選項或題組裡有圖、表、座標圖、實驗裝置、地圖、照片、複雜排版的數學式或化學結構，而且無法用文字或 Markdown 表格完整表達的，都要附圖：
- 命名：img/<題本id>/q<題號>.png；題組圖 img/<題本id>/g-<題組id>.png；選項是圖時 q<題號>-opts.png。
- 你能處理 PDF／圖片時（有程式工具）：把該頁轉成高解析圖（至少 150 dpi），裁切出該題的圖（留一點白邊、不要切到其他題），寬度 800～1600 px，存成上述檔名並一起打包。
- 你不能處理時：JSON 照樣寫好 img 路徑，並在最後輸出【截圖清單】表格：檔名｜原檔第幾頁｜截取範圍（例如「第12題右側的電路圖，含 R1、R2 標示」）｜是否整題截圖。我會自己截圖、用這些檔名存進 img 資料夾。
- 整題截圖：題目（題幹＋選項）幾乎都是數學式、化學結構、圖形選項，文字轉寫容易出錯時，可以改用整題截圖：stem 寫一句簡短描述（例如「如圖，求 x 的範圍」），不寫 choices，改寫 "opts": 選項數量，img 放整題截圖，answer 照常寫字母。表格、一般文字仍然盡量轉寫。

# 詳解結構
1. **考點**。2. **解題過程**（一步一步，計算放在 ``` 區塊）。3. **選項分析**（錯誤選項錯在哪；多選每個選項都說明）。4. **延伸**（選填）。
約 100～300 字，繁體中文，不能用 LaTeX（用 Unicode：x²、√2、π、≤、≠、H₂O；分數寫 a/b）。若官方答案與你算的不同，不要改答案，在 explain 第一行寫「⚠ 答案存疑：……」並列進【需要確認】。

# 輸出格式（xd-bundle/1）
```json
{
  "schema": "xd-bundle/1",
  "subjects": [ { "id": "xc_eng", "name": "學測英文", "theme": "lang" } ],
  "sets": [
    {
      "schema": "xd-bank/1",
      "set": { "id": "xc-eng-113", "subject": "xc_eng", "name": "113 學測 英文", "year": 113, "path": ["學測歷屆", "英文"], "source": "大學入學考試中心 113 學年度學科能力測驗" },
      "groups": [ { "id": "g31-35", "title": "閱讀測驗（第31–35題）", "text": ["文章第一段", "文章第二段"] } ],
      "questions": [
        { "n": 1, "type": "single", "stem": "……", "choices": ["…", "…", "…", "…"], "answer": "C", "explain": "……", "tags": ["詞彙"] },
        { "n": 31, "type": "single", "group": "g31-35", "stem": "……", "choices": ["…", "…", "…", "…"], "answer": "A", "explain": "……", "tags": ["閱讀測驗"] },
        { "n": 12, "type": "single", "stem": "如圖所示的電路，求電流比。", "img": ["img/xc-sci-113/q12.png"], "opts": 5, "answer": "B", "explain": "……", "tags": ["電路"] }
      ]
    }
  ]
}
```
- set.id：英文、數字、-、_；建議「科目-年份」或「科目-考試-年份」。有年份就寫 year（民國或西元皆可，照原考卷）。
- subjects 定義用到的科目（id 小寫英文數字底線；theme：lit 語文、lang 外語、math 數學、calc 計算應用、hist 人文社會、sci 自然醫學視光、mix 綜合）。

# 交付
- JSON 必須合法（不能有註解、結尾逗號；字串內雙引號寫成 \"；多行文字用字串陣列）。
- 你能建立檔案時：<題本id>.json＋img/ 資料夾，打包成 zip。不能時：先寫「檔名：<題本id>.json」，再用 ```json 程式碼區塊輸出。
- 程式碼區塊外只放：【截圖清單】、【需要確認】。
- 一次輸出不完：在完整一題之後停止，寫「【未完，請回覆「繼續」】」；之後每批用相同 set.id、題號接續（會自動合併）。

【我的設定】
科目與 id：（例如：學測英文，xc_eng）
題本名稱、id、年份：（例如：113 學測 英文，xc-eng-113，113）
分類階層 path：（例如：["學測歷屆", "英文"]）
````

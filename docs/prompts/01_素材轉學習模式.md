# 01 素材 → 學習模式課程

> 把講義、課本、PDF、筆記、投影片改寫成遊戲的「📘 學習模式」課程：邊學邊練、每段打一隻怪、課末打魔王。
> **一般用法**：素材一章以內 → 直接用「1-B 產出課程」。素材很多（整本書、整學期）→ 先用「1-A 盤點與規劃」，確認大綱後再用 1-B，一次做一個單元。
> 輸出太長被截斷時，貼「1-C 繼續」。

## 1-A 盤點與規劃（素材多時先做）

```text
你是資深的課程設計師與學科專家。我會提供學習素材，要把它改編成一個「學習遊戲」的課程。這一步只做盤點與規劃，不要寫課程內容。

請依序完成：

一、素材盤點（最重要，之後用來確認沒有遺漏）
把素材裡「所有需要學的東西」逐條列成清單，編號 M1、M2、M3…，每條一行，標註類型與位置：
- 類型：定義／概念、原理機制、公式（含推導）、定理規則、數據與常數、分類與清單、流程步驟、比較、構造（解剖、儀器）、圖表、例題、例外與注意事項、口訣、臨床或生活應用、歷史與人物、原文（課文、條文）。
- 位置：頁碼或章節標題。
- 素材中的每一個小標題、粗體字、表格、圖、例題、備註、課本邊欄都要被列到；一個表格或一張圖若包含多個知識點，要拆成多條。
- 若我同時提供題庫（題目檔、練習題、考古題），另外建立【題庫詞彙表】，編號 V1、V2…：把所有題目（題幹、選項、詳解）用到的標籤、符號與縮寫（例如 Pe、Pv、d̄、JCC）、公式、常數與數值、專有名詞、英文名稱逐條列出，標明第一次出現在哪一題。**教材的深度要追上題目**：V 的每一條之後都必須在課程裡被教到，而且教到足以解出題庫最難的題（題目維持原本的難度，不要為了遷就教材而簡化或刪題）。

二、分層與分單元
1. 依素材本身的結構決定分類階層 path（最多 5 層），例如：
   - 高中：["高二", "上學期", "第3章 光的反射與折射"]
   - 大學：["解剖學", "第5章 上肢", "肩部與腋窩"]
   - 學測總複習：["學測總複習", "自然", "物理", "力學"]
   - 證照：["驗光師國考", "眼球光學", "屈光狀態"]
2. 切成「單元」：一個單元＝一節或一個主題，含 2～6 課。
3. 每一課 10～20 分鐘，2～6 張概念卡，一張卡只講一個觀念。
4. 順序要符合學習邏輯：先備知識 → 核心觀念 → 應用 → 綜合。素材順序不好時可以重排，並說明理由。

三、輸出規劃表
對每個單元：單元 id（小寫英數與 -，例如 anat-upper-limb-bones）、標題、path、一句話簡介、難度（1 基礎／2 標準／3 進階）。
對每一課：課 id（l1、l2…）、標題、學習目標 1～3 條、概念卡清單（卡片標題＋涵蓋哪些 M 編號）、最常見的 2～4 個迷思或錯誤、適合的範例、是否需要「圖解」（看圖認構造）或「互動動畫」（動態過程、光路、圖形變換），以及 2～4 個關鍵字。

四、覆蓋檢查
列出每個 M 編號（以及有題庫時的每個 V 編號）被放在哪個單元哪一課；沒有放進課程的，寫出理由（例如與 M12 重複）。不可以有沒交代的 M 或 V。V 沒被素材教過的（題庫比素材深），另外列成【題庫超出素材的部分】，由我決定要補教材還是刪題。

五、疑點
列出素材中講得不清楚、可能有錯、互相矛盾、或缺少前備知識的地方。

用繁體中文。完成後停下來，等我確認或修改規劃，再進行下一步。

【我的設定】
學習者：（例如：視光系一年級／高二學生／準備學測的高三生／國考考生）
科目：（例如：解剖學）
素材說明：（例如：上傳的是課本第5～6章 PDF 與老師的投影片）
```

## 1-B 產出學習課程（主要提示詞）

````text
你是頂尖的學科教師兼教學設計師。請把我提供的學習素材（或我們剛確認的規劃）寫成「學習遊戲」的課程檔。

# 最高原則
1. 完整：素材中的每個知識點、數字、單位、條件、例外、分類清單、表格內容、圖中標示的構造，都要出現在課程裡。不可以因為「太細」而省略；太多就多開幾張卡或幾課。
2. 好懂：先白話、後專業。每個專有名詞第一次出現要解釋。用比喻、例子、對照表幫助理解。寫給「第一次學這個的學生」看，但內容深度不打折。
3. 正確：只寫素材有的內容，或該領域教科書公認的基本事實。不確定的不要寫，列進【需要確認】。數字、公式、正負號、單位全部再核對一次。
4. 固定節奏：每一課都照下面的節奏，遊戲靠它運作（每段會出現一隻怪物，答對才能打倒它）。

# 每一課的固定節奏
intro（導入）→［card（概念卡）→ 1～2 題 check（檢核）］重複 2～6 次 → example（範例拆解）→ practice（實戰）→ recap（回顧）
- 第一步一定是 intro，最後一步一定是 recap。
- 每張 card 後面「緊接」至少 1 題 check。
- 需要看圖認構造時，在相關 card 後面加一個 diagram（它本身就是測驗，可取代該卡的 check）。
- 需要動態理解時，在相關 card 後面加一個 interactive，再接 check。
- 一課 8～20 步。

# 概念卡（card）怎麼寫
每張卡只講一個觀念，依需要使用下面的段落（沒有的可省略，順序不變）：
① **一句話定義**：精確、可以背的版本（粗體關鍵詞）。
② **白話說明**：用日常語言或比喻再說一次。
③ **為什麼**：原理、機制、推導、因果關係。
④ **怎麼用**：判斷步驟、解題流程、使用條件。
⑤ **例子**：至少一個具體例子；數理一定要有帶數字的例子。
⑥ **易錯與比較**：常見誤解、容易混淆的概念對照表。
⑦ **連結**：和前面學過的、後面會學的觀念有什麼關係。
- 長度 150～500 字；超過就拆成兩張卡，中間插檢核題。
- 大量的清單或分類（例如 12 對腦神經、各種屈光異常）用 Markdown 表格完整列出，並把重點做成記憶卡（flash）。
- keys 放 2～4 個最重要的重點；tip 放小叮嚀或口訣（口訣請標明「口訣」）。

# 各類素材的特別要求
【數學】定義→定理→推導要點→使用條件→解題步驟；符號第一次出現就說明；每個公式附一個數值例子；點出邊界條件與常見計算錯誤。
【物理、生理光學、幾何光學、視光學】
- 每個物理量第一次出現：符號、意義、單位（例如屈光度 D = 1/公尺）。
- 正負號慣例（光行進方向、物距像距、會聚發散、實像虛像）在單元開頭的卡片明確寫出，整個單元一致。
- 公式要寫出由來或推導要點與適用條件（例如薄透鏡、近軸光線），每個公式附數值例子，逐步計算並檢查單位與正負號。
- 光路圖、成像、調節、屈光異常矯正這類「會動」的內容，優先做 interactive（可拖曳物體或調整鏡片度數，即時顯示成像位置與數值）。
- 連到臨床或生活應用（近視、遠視、散光、老花、眼鏡與隱形眼鏡度數換算、驗光流程）。處方寫法（如 -2.00DS/-0.75DC×180）要解釋每個部分。
- 生理數值（如眼的屈光力、瞳孔大小、調節幅度）以素材為準；素材沒有而你補充的，標「（常用參考值）」。
【化學】巨觀現象、微觀粒子、化學符號三層對照；反應式要平衡並標狀態；計算題寫出每一步的單位換算。
【生物、生理學】構造 → 功能 → 調控 → 失常或疾病；流程用 order 檢核（排出正確順序）；相似構造做比較表。
【解剖學、組織學、眼球構造】每個構造都要交代：
- 中文名、英文名（素材有拉丁名就一併列出）；
- 位置（用解剖方位術語：前後、上下、內外側、近遠端、淺深），以及和周圍構造的相鄰關係；
- 形態或分部、功能；
- 血液供應、神經支配、淋巴引流（素材有提到的）；肌肉要有起點、止點、作用、神經支配（用表格）；
- 臨床相關（素材有提到的）。
- 構造多的內容一定要做 diagram（看圖點出構造）。圖片的取得方式見下方「圖片」。
【國文】文言文保留原文不改動，逐句附白話翻譯；解釋關鍵字詞（字音、字形、詞義、詞性、特殊用法）；說明篇旨、段落結構、修辭與寫作手法、作者與文學常識；閱讀理解提供判讀方法。
【英文、外語】單字列出詞性、中文、例句（附中譯）、常見搭配、同義反義、字根字首；文法規則附正確例句與錯誤例句；閱讀題型提供解題策略。
【社會（歷史、地理、公民）、法律、管理】時間順序用 order 檢核；因果關係鏈；比較表；名詞定義精確；地圖、統計圖要教判讀方法；法條保留關鍵原文用語。
【學測、會考、國考等考試】依該考試的範圍與題型設計檢核與實戰題：題組、多選、混合題、情境素養題；在卡片中點出「考試常考的角度」。
【語言程度】依【我的設定】的學習者調整用詞；國中以下多用比喻，大學以上保留專業術語並附英文。

# 檢核題（check）
- 每題只考剛學的觀念；題型輪流使用。答案唯一、沒有歧義。
- kind：
  - "single" 單選：choices 3～5 個，answer 寫正確選項字母，例如 "B"。
  - "multi" 多選：answer 寫所有正確選項字母，例如 "AC"（至少 2 個正確）。
  - "tf" 是非：answer 寫 true 或 false。
  - "fill" 填答：answer 是陣列，列出所有可接受的寫法（有無單位、全名簡稱、英文中文、數值的不同寫法），例如 ["+2.50", "2.5", "+2.5D", "2.50"]。答案要短（一個詞或一個數）。
  - "order" 排序：items 依「正確順序」寫 3～7 項（遊戲會自動打亂）。適合流程、年代、步驟、傳導路徑。
  - "self" 自評：answer 寫參考答案，適合申論、翻譯、畫圖、口述。
- hint：第一次答錯時顯示，只引導思路，不可以直接說出答案。
- explain：答完後的解說。說明為什麼對，並逐一說明錯誤選項錯在哪、對應哪種常見迷思。
- 誘答選項要來自真實的常見錯誤（公式用錯、正負號、混淆相似構造、忽略條件），不要放荒謬選項。正確答案的字母位置要分散。

# 範例（example）
一個有代表性的題目，拆成 3～6 步，每步只做一件事（「先找已知條件」「判斷用哪個公式」「代入」「檢查單位與合理性」）。answer 寫最後結論與一句「這題的關鍵」。

# 實戰（practice）
- pick.match：2～5 個關鍵字，**取自本課 teaches 裡的詞**（要和題庫標籤一致，例如「屈光度」「近視」），遊戲只會從本單元 banks 裡「已教過」的題目抽題；pick.n 抽幾題（1～3）。不要用太籠統、各單元都會出現的詞（例如單獨的「屈光力」「聚散度」），否則抽不準。
- qids：先留空陣列 []。
- checks：2～3 題接近正式考試難度的自編題（格式同 check，但不寫 type），要跨本課的多個觀念。

# 回顧（recap）
- points：5～10 條，完整濃縮本課所有重點（看完 points 就能複習整課）。
- flash：本課 4～10 張記憶卡（front 問題、back 答案），涵蓋定義、公式、數值、構造名稱。
- next：下一課預告一句（最後一課可省略）。
- 另外，重要的 card 可以各自帶一張 flash。

# 圖片
- 能用文字、Markdown 表格表達的就不用圖。
- card 的 img 可以放一張或多張圖（字串或字串陣列），圖片來源寫在 img_source。
- diagram（看圖認構造）：img 放一張圖，points 列出要學的標記點（5～15 個）：
  - x、y 是標記點在圖片中的位置，以圖片寬、高的百分比表示（0～100，左上角是 0,0），點要落在構造本身上，不是落在圖上的文字標籤。
  - 你能看到圖片、可以估出位置時才填 x、y；無法確定時請填 null，學生第一次打開時會自己在圖上點出位置。
  - 用來測驗的圖最好「沒有印上名稱標籤」，否則測驗太簡單。只有有標籤的圖時，在【圖片清單】註明「需要遮住標籤」。
  - mode 用 "both"（先探索、再測驗），只想展示不測驗時用 "explore"。
- 圖片從哪裡來（依序）：
  1. 素材裡的圖：你能處理檔案時，把該頁轉成圖片並裁切出那張圖；不能時列進【截圖清單】（檔名、第幾頁、截哪一塊）。
  2. 網路上可合法使用的圖（解剖、構造、地圖等）：優先 Wikimedia Commons、OpenStax（CC BY）、Servier Medical Art（CC BY）、BodyParts3D（CC BY-SA）、Gray's Anatomy 1918 年版圖（公有領域）、政府與開放資料。你能上網下載時就下載並一起打包；不能時列出「圖片直接網址＋要存成的檔名」。一律在 img_source 或 source 寫出作者／網站與授權。
  3. 找不到合適的圖時，可以用 SVG 或 interactive 畫示意圖，或改用文字表格。
- 圖片檔名與路徑一律用：img/<單元id>/<英數檔名>.png（或 .jpg）。

# 互動與動畫（interactive）——需要時才用
適合：光路與成像、透鏡與度數、波動、電路、力與運動、函數圖形變換、統計分布、化學平衡移動、生理流程（神經傳導、心動週期、房水循環）等「會動、會變」的內容。不需要就不要做。
規則：
- html 是一份完整、獨立的 HTML（可寫成字串陣列一行一個元素），只用原生 HTML、CSS、JavaScript，可用 SVG 或 canvas。
- 不可載入任何外部檔案（不可用 CDN、外部字型、fetch、圖片網址）；不可使用 alert、localStorage、表單送出。
- 版面寬度 100%、高度不超過 560px，文字至少 14px，標示用繁體中文，數值要有單位。
- 提供滑桿或按鈕讓學生操作，畫面上即時顯示關鍵數值，並附一行「觀察重點」。
- 物理與數學必須正確（公式、正負號、比例）。
- task 寫一句具體任務，例如「把物體從 2f 移到 f 以內，觀察像的變化」；interactive 後面接一題 check 驗收。

# 分類階層（path）
path 是課程列表的分類階層，由大到小，最多 5 層，依素材結構填寫，例如 ["高一", "上學期", "第2章 細胞的構造"]、["解剖學", "第5章 上肢", "肩部"]。同一系列的單元，每一層的文字要一模一樣（包含空格與標點）。

# 題庫連結與深度對齊（有題庫時必做；沒有題庫也要寫 teaches）
學習模式的「實戰」會從題庫抽題。題目要保持深度（應用、綜合、臨床情境、多步驟計算），所以**教材要補到夠深**，否則學生會被問到沒學過的東西。原則：題目不降級，教材補上去。所以：
1. **深度對齊**：課程要教到題庫裡所有題目（題幹、選項、詳解）用到的每一個觀念、符號、公式、數值與英文縮寫。有題庫時，先建立【題庫詞彙表】（V1、V2…），確認每一條都在某張概念卡被**定義並示範**，而且在「第一次被題目用到之前」就教過。題庫考得比教材深的地方，要補寫概念卡；不要刪題目、不要把題目改簡單、也不要假裝教過。
2. **單元 banks**：單元寫 "banks": ["題本id", …] ＝這個單元負責的題本（題本的 set.id）；"prior": ["前面單元的題本id"] ＝可以拿來複習的前面單元。沒有題庫時省略。
3. **課 teaches**：每一課寫 "teaches": ["標籤詞", …] ＝這一課教了哪些題庫標籤（tags）。要寫題庫裡實際用的標籤詞，而且教材中真的有教；沒教的觀念不可以列進去。一題要被抽到，它所有的標籤都必須已在「這一課（含更早的課）」教過。
4. **順序**：一個觀念要在使用它的卡片、檢核與實戰之前教；不可以在前面的課用到後面課才教的觀念。需要用到前面單元的觀念時，在卡片的「連結」段落點出來。
5. **用詞一致**：課程用詞與題庫標籤不同時（例如標籤「焦度計」、教材寫「驗度儀」），在卡片裡把兩個說法都寫出來。
6. **深度標準**：不只教定義，要教到「能解出題庫最難的題」——每種題型的解題方法、多步驟計算的完整示範（example）、常見陷阱與易混淆對照、臨床或情境應用、跨觀念整合。題庫最難的 5～10 題（level 3、多選、題組、非選、臨床案例）在課程裡都要有對應的範例或進階卡；進階卡的標題可以標「進階：」。
7. **符號先定義**：任何符號（Pe、Pv、d̄、n₂…）第一次出現的卡片就要說明它是什麼、單位、與哪個量相關；整個單元用同一套符號。

# 交付方式
1. JSON 必須是合法 JSON：不能有註解、不能有結尾多餘的逗號、字串裡的雙引號寫成 \"、不能在字串裡直接換行（改用字串陣列）。
2. 你能建立檔案時（有程式執行或檔案下載功能）：把 JSON 存成 <單元id>.json，所有圖片放在 img/<單元id>/，整個資料夾壓縮成一個 zip 讓我下載。
3. 你不能建立檔案時：在回覆中先寫一行「檔名：<單元id>.json」，接著用 ```json 程式碼區塊輸出完整 JSON。我會把整段回覆存成 .md 檔導入。
4. 程式碼區塊外只放：【圖片清單】、【截圖清單】、【覆蓋對照】、【需要確認】。
   - 【圖片清單】表格：檔名｜內容｜來源網址｜授權｜是否需要遮住標籤。
   - 【截圖清單】表格：檔名｜素材第幾頁｜要截取的範圍。
   - 【覆蓋對照】素材的每個小節、表格、圖、例題 → 放在哪一課第幾步（有做 1-A 時用 M 編號對照）。
   - 【題庫覆蓋對照】（有題庫時）：題庫詞彙表的每一條 → 在哪一課第幾步被定義；以及題庫比教材深的地方你新補的內容清單（教材補上去，題目不動）。
5. 內容太長時：在「完整的一課」結束處停止，輸出目前完成的部分（仍然是完整合法的 JSON，包含 schema、subjects、單元的完整欄位，但 lessons 只含已完成的課），最後寫「【未完，請回覆「繼續」】」。之後每次輸出下一批完整的課，單元 id 相同、lesson id 接續，遊戲會自動合併。

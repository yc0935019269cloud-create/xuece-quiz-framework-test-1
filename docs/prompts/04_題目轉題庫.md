# 04 既有題目 → 題庫

> 把現成的題目（考卷、學測歷屆、國考題、題本、Word、網頁、Excel）原封不動轉進遊戲，會自動分科目、年份、題本。
> 同時要寫詳解 → 用「03 的 3-B」。只轉格式 → 用這裡的 4-A。一次要處理很多年、很多科 → 4-B。
> 題目在 Excel 裡 → 看最下面「自己用 Excel」，不必經過 AI。

## 4-A 轉換一份考卷／題本

````text
請把我上傳的題目「忠實地」轉成遊戲的題庫 JSON。這是格式轉換，不是改寫。

# 轉換規則
1. 題號、題幹、選項、答案必須和原文一字不差（只修正明顯的 OCR 亂碼、斷行、多餘空白）。不可改寫、刪減、合併、重新排序。
2. 選項只放內容，不含 (A)、(1)、① 這些標號。原本用數字標號的，answer 換成字母：(1)→A、(2)→B…；多選「1,3,5」→ "ACE"。
3. 題型判斷：
   - 單選 single；多選 multi（題幹或說明寫「多選」、答案有多個）；是非 tf（○×、對錯、T/F，answer 寫 true/false）；
   - 填充、簡答且答案唯一 → fill（answer 寫答案，accept 列出所有可接受的寫法：有無單位、全形半形、中英文、簡稱）；
   - 申論、計算過程、作文、翻譯、答案不唯一 → open（answer 寫參考答案或評分原則；沒有就寫「（無參考答案）」）。
   - 混合題（一題內有選擇＋填答＋非選）：拆成多題，題號寫成 "20-1"、"20-2"…，放在同一個題組。
4. 題組：多題共用同一篇文章、圖表、情境、數據時，放進 groups（文章完整轉寫），題目用 group 指向它。
5. 考卷前的作答說明（例如「第 1 至 10 題為單選題，每題 2 分」）不用轉；但若包含解題必要的資訊（常數、單位規定、符號定義），寫進該區第一題的題幹開頭或題組文章。
6. 答案：
   - 以答案卷／官方答案為準。答案卷缺某題時，自己解出來並列進【需要確認】（標明「AI 推測」）。
   - 送分題或有多個答案都給分：answer 寫官方公告的答案之一，並在 explain 註明「官方公告：本題 ○ 與 ○ 均給分」。
7. 原本附的詳解就放進 explain（保留原文）；沒有就寫空字串 ""。
8. tags：原卷有標考點就照抄；沒有就依題意給 1～3 個考點關鍵字（不可以寫出答案）。若我同時提供學習課程，tags 請優先使用課程裡實際教的名詞，這樣課程的實戰才抽得到。
9. 表格用 Markdown 表格轉寫；上標下標用 Unicode（x²、H₂O）；不能用 LaTeX；分數寫 a/b。

# 圖片與截圖（題目有圖時必做）
凡是題目、選項或題組含有圖、表、座標圖、實驗裝置、電路、地圖、照片、解剖圖，或複雜排版的數學式、化學結構，無法用文字或 Markdown 表格完整表達時：
- 命名：img/<題本id>/q<題號>.png；題組圖 img/<題本id>/g-<題組id>.png；選項是圖時 img/<題本id>/q<題號>-opts.png。
- 你能處理 PDF／圖片時（有程式工具）：把該頁轉成至少 150 dpi 的圖，精準裁切出該題需要的圖（留少許白邊、不要切到別題），寬度 800～1600 px，存成上述檔名，和 JSON 一起打包。
- 你不能處理時：JSON 裡照樣寫好 img 路徑，並在最後輸出【截圖清單】：檔名｜原檔第幾頁｜截取範圍（越具體越好，例如「第 12 題右側電路圖，含 R1、R2、電池標示」）｜整題或局部。我會自己截圖、用這些檔名存進 img 資料夾。
- 整題截圖模式：題幹和選項幾乎都是數學式、化學結構、圖形選項，文字轉寫容易出錯時，改用整題截圖：stem 寫一句簡短描述，不寫 choices，改寫 "opts": 選項數量，img 放整題截圖，answer 照常寫字母。
- 解剖圖、構造圖有「編號」要辨識時，可以用 marks 在圖上標編號：[{ "x": 35, "y": 42, "label": "1" }]（x、y 為圖片寬高百分比）；圖上本來就印有編號就不需要 marks。

# 輸出格式（xd-bundle/1）
```json
{
  "schema": "xd-bundle/1",
  "subjects": [ { "id": "xc_sci", "name": "學測自然", "theme": "sci" } ],
  "sets": [
    {
      "schema": "xd-bank/1",
      "set": { "id": "xc-sci-113", "subject": "xc_sci", "name": "113 學測 自然", "year": 113, "path": ["學測歷屆", "自然"], "source": "考試名稱與年度", "source_url": "（選填）原卷網址" },
      "groups": [ { "id": "g5-6", "title": "第 5–6 題為題組", "text": ["題組文章……"], "img": ["img/xc-sci-113/g-g5-6.png"] } ],
      "questions": [
        { "n": 1, "type": "single", "stem": "……", "choices": ["…", "…", "…", "…", "…"], "answer": "D", "explain": "", "tags": ["……"] },
        { "n": 2, "type": "multi", "stem": "……（多選）", "choices": ["…", "…", "…", "…", "…"], "answer": "BDE", "explain": "", "tags": ["……"] },
        { "n": 5, "type": "single", "group": "g5-6", "stem": "……", "choices": ["…", "…", "…", "…"], "answer": "A", "explain": "", "tags": ["……"] },
        { "n": 12, "type": "single", "stem": "如圖，……", "img": ["img/xc-sci-113/q12.png"], "opts": 5, "answer": "C", "explain": "", "tags": ["……"] },
        { "n": "20-1", "type": "fill", "group": "g20", "stem": "……", "answer": "3", "accept": ["3", "三"], "explain": "", "tags": ["……"] }
      ]
    }
  ]
}
```
- set.id：英文、數字、-、_，建議「科目-年份」；全部題本中唯一。year：有年份就寫（照原卷，民國或西元）。
- subjects：定義用到的科目（id 小寫英文數字底線；theme 選 lit 語文、lang 外語、math 數學、calc 計算應用、hist 人文社會、sci 自然醫學視光、mix 綜合）。
- 長文字可寫成字串陣列（一個元素一行）。

# 交付
- JSON 必須合法（不能有註解、結尾逗號；字串內雙引號寫成 \"）。
- 你能建立檔案時：<題本id>.json＋img/ 資料夾，打包成 zip 讓我下載。不能時：先寫「檔名：<題本id>.json」，再用 ```json 程式碼區塊輸出完整 JSON。
- 程式碼區塊外只放：【截圖清單】、【需要確認】（答案缺漏、看不清楚、疑似印錯）。
- 題目多、一次輸出不完：在完整一題之後停止，寫「【未完，請回覆「繼續」】」；之後每批用相同 set.id、題號接續（遊戲會自動合併）。

# 輸出前自我檢查
□ 題數和原卷一致，沒有漏題、重複題；題號正確。
□ 每題答案都對照過答案卷；多選字母正確。
□ 有圖的題目都有 img 並列入【截圖清單】（或已打包）。
□ JSON 合法。

【我的設定】
科目與 id：（例如：學測自然，xc_sci）
題本名稱、id、年份：（例如：113 學測 自然，xc-sci-113，113）
分類階層 path：（例如：["學測歷屆", "自然"]）
````

## 4-B 一次處理很多份（多年份、多科目）

```text
（使用方式：先把上面「4-A」的整段提示詞貼上，再接著貼這一段，一起送出。）

我會上傳很多份考卷與答案（可能是好幾個年度、好幾個科目，例如學測 111～115 年的國文、英文、數學A、數學B、社會、自然）。請依照「4-A 轉換一份考卷」的全部規則處理，另外：

1. 先列出你辨識到的清單：每份的科目、年度、題數、有沒有答案卷、有幾題需要截圖。等我確認後再開始轉換。
2. 每一份考卷是一個獨立題本（set），id 用「科目-年份」（例如 xc-eng-113），name 用「年份 考試 科目」（例如「113 學測 英文」），year 填年度，path 用 ["考試名稱歷屆", "科目"]。
3. 同一個科目在不同年份用同一個 subject id；subjects 只定義一次。學測建議 id：xc_chi 國文、xc_chiw 國寫、xc_eng 英文、xc_ma 數學A、xc_mb 數學B、xc_soc 社會、xc_sci 自然。
4. 一次輸出一份題本（一個 JSON），輸出完寫「【第 N／總數 份完成，請回覆「繼續」】」，我回覆後再做下一份。
5. 每份最後附該份的【截圖清單】與【需要確認】。截圖一律存到 img/<題本id>/。
```

## 自己用 Excel（不經過 AI）

1. 第一列打欄名（中英文都可以）：`題號、題型、題目、選項A、選項B、選項C、選項D、選項E、答案、可接受答案、詳解、標籤、圖片、年份、科目、題本`
2. 一列一題。題型寫 單選／多選／是非／填答／非選（空白時自動判斷）；答案寫 `B`、`ACD`、`對`／`錯`、或填答的答案；可接受答案用 `|` 隔開。
3. 「年份、科目、題本」可以每列不同：同一個檔案裡不同年份、科目的題目會自動分成不同題本。
4. 另存成「CSV UTF-8（逗號分隔）」，和圖片放在同一個資料夾，用「📥 導入素材」導入。

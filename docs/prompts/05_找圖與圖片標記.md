# 05 找圖與圖片標記（解剖、構造、地圖、儀器）

> 解剖學、眼球構造、組織切片、地圖、實驗儀器這類「要看圖認位置」的內容，用這裡的提示詞做成遊戲的「🔍 圖解」：學生先點標記看說明，再做「點出○○在哪」的辨識測驗，還會打怪。
> 標記座標不準或沒有座標都沒關係：遊戲裡按「📍 調整標記」就能自己點出正確位置。
> 5-A 做完整的圖解單元（找圖＋標記＋檢核題）；5-B 已經有圖，只要標記；5-C 做看圖辨識的題庫題目。

## 5-A 找圖並做成圖解單元

````text
你是解剖學（或該科）的教學設計專家，也熟悉開放授權的教學圖片。請依我指定的主題，找合適的圖片並做成學習遊戲的「圖解」單元。

# 一、找圖
1. 來源（依優先順序，必須是可合法教學使用的）：
   - Wikimedia Commons（公有領域、CC BY、CC BY-SA）
   - OpenStax《Anatomy and Physiology》等 OpenStax 教科書（CC BY 4.0）
   - Servier Medical Art（CC BY 4.0）、BodyParts3D（CC BY-SA）、Gray's Anatomy 1918 年版圖譜（公有領域）
   - 政府、學術機構的開放資料；我上傳的素材中的圖
   不要使用有版權限制的商業圖譜或網站圖片。
2. 選圖原則：
   - 每張圖聚焦一個部位或視角（例如「右肩前面觀」「眼球水平切面」），解析度清楚（寬 800 px 以上）。
   - 做辨識測驗的圖要「沒有印上名稱標籤」，或只有編號線。只找到有文字標籤的圖時：你能處理圖片就把標籤遮掉（用與背景相近的色塊蓋住文字，保留指示線或改成編號）；不能處理就在清單註明「需要遮住標籤」。
   - 同一個構造需要多個視角時（前面觀、後面觀、切面），分成多張圖、多個圖解。
3. 你能上網下載並處理檔案時：下載原圖，必要時裁切、縮放到寬 1000～1600 px、遮住標籤，存成 img/<單元id>/<英數檔名>.png（或 .jpg），和 JSON 一起打包成 zip。
4. 你不能下載時：在【圖片清單】列出每張圖的「直接圖檔網址」（Wikimedia 要給 upload.wikimedia.org 開頭的原始檔網址）、頁面網址、作者、授權、要存成的檔名、是否需要遮住標籤。

# 二、標記點
- 每張圖 5～15 個標記點，依學習重要性挑選（素材有提到的構造一定要有）。
- 每個點：name（中文名＋英文名，素材有拉丁名也可加上）、desc（1～3 句：位置與相鄰構造、功能、神經／血管，或臨床重點）。
- 座標 x、y 是「標記點在圖片中的位置」，以圖片寬、高的百分比表示（0～100，左上角為 0,0，右下角為 100,100），點要落在構造本身（不是落在標籤文字或指示線末端的文字上），小構造點在中心、大構造點在最具代表性的位置。
- 你能看到圖片（或自己下載處理了圖片）時才填座標，並逐點檢查一次；不確定就填 null，學生第一次打開時遊戲會請他依序在圖上點出位置。寧可 null，不要亂猜。

# 三、做成課程
每個圖解放在一課裡，前後配合概念卡與檢核題，照這個節奏：
intro → card（這個部位的整體概念、方位與分區，附圖 img）→ diagram（圖解探索＋辨識測驗）→ card（重要構造的細節：用表格整理位置、功能、神經、血管、臨床）→ check（1～2 題：位置關係、功能、臨床推理）→（可再一組 card→diagram 換視角）→ example（病例或情境推理，分 3～5 步）→ practice → recap（重點＋記憶卡：構造名稱中英對照、功能、神經支配）。

# 輸出格式（xd-bundle/1）
```json
{
  "schema": "xd-bundle/1",
  "subjects": [ { "id": "anat", "name": "解剖學", "theme": "sci", "words": ["骨骼", "肌肉", "神經", "血管"] } ],
  "packs": [
    {
      "schema": "xd-learn/1",
      "id": "anat-eyeball",
      "subject": "anat",
      "path": ["解剖學", "眼與視覺"],
      "unit": "眼球構造",
      "title": "眼球的構造",
      "desc": "一句話簡介",
      "level": 2,
      "source": "依據素材或參考書",
      "lessons": [
        {
          "id": "l1",
          "title": "眼球水平切面",
          "goals": ["能在圖上指出眼球三層膜與內容物", "能說出各構造的功能"],
          "steps": [
            { "type": "intro", "title": "……", "body": ["……"] },
            { "type": "card", "title": "眼球的三層膜", "body": ["……", "", "| 層 | 構造 | 功能 |", "|---|---|---|", "| 外層（纖維層） | 角膜、鞏膜 | …… |"], "keys": ["……"], "img": "img/anat-eyeball/eye-section-overview.png", "img_source": "作者, Wikimedia Commons, CC BY-SA 4.0", "flash": { "front": "……", "back": "……" } },
            {
              "type": "diagram",
              "title": "眼球水平切面：找出構造",
              "body": "先點每個數字看說明，再按「開始辨識測驗」。",
              "img": "img/anat-eyeball/eye-section-unlabeled.png",
              "source": "作者, Wikimedia Commons, CC BY-SA 4.0（已移除標籤）",
              "mode": "both",
              "points": [
                { "name": "角膜 Cornea", "desc": "眼球最前方透明的纖維層，屈光力最大（約占全眼的三分之二）", "x": 12.5, "y": 50 },
                { "name": "水晶體 Lens", "desc": "雙凸透明構造，由睫狀小帶懸吊；調節時改變曲率", "x": null, "y": null }
              ]
            },
            { "type": "check", "kind": "single", "q": "……", "choices": ["…", "…", "…", "…"], "answer": "B", "hint": "……", "explain": "……" },
            { "type": "example", "title": "……", "problem": "……", "steps": ["……", "……", "……"], "answer": "……" },
            { "type": "practice", "title": "實戰", "qids": [], "pick": { "match": ["眼球", "角膜"], "n": 2 }, "checks": [ { "kind": "multi", "q": "……", "choices": ["…", "…", "…", "…", "…"], "answer": "AD", "explain": "……" } ] },
            { "type": "recap", "points": ["……"], "flash": [ { "front": "……", "back": "……" } ] }
          ]
        }
      ]
    }
  ]
}
```
規則補充：
- 檢核題 kind：single（answer 寫字母 "B"）、multi（"AD"）、tf（true/false）、fill（答案陣列，列出中文、英文、常見別名）、order（items 依正確順序，例如光線通過眼球的順序、神經傳導路徑）、self（參考答案）。每題要有 hint（不直接給答案）與 explain（說明為什麼、錯誤選項錯在哪）。
- 數值以素材為準；素材沒有而你補充的標「（常用參考值）」。
- 不能用 LaTeX；多行文字用字串陣列。

# 交付
- JSON 必須合法（不能有註解、結尾逗號；字串內雙引號寫成 \"）。
- 能建立檔案：<單元id>.json＋img/<單元id>/ 所有圖，打包 zip。不能：先寫「檔名：<單元id>.json」，再用 ```json 程式碼區塊輸出。
- 程式碼區塊外附：【圖片清單】（檔名｜內容與視角｜直接圖檔網址｜頁面網址｜作者｜授權｜是否需要遮住標籤）、【需要確認】。
- 太長就在完整一課後停止，寫「【未完，請回覆「繼續」】」，之後用相同單元 id、lesson id 接續。

【我的設定】
科目與 id：（例如：解剖學，anat）
主題與範圍：（例如：上肢的骨骼與肌肉，含肩、上臂、前臂、手）
學習者：（例如：視光系一年級；醫學系；高中生物）
分類階層 path：（例如：["解剖學", "第5章 上肢"]）
我上傳的素材：（例如：課本第5章 PDF；或沒有素材，依標準教科書範圍）
````

## 5-B 已經有圖，只要標記

````text
我上傳了一張（或多張）圖片，請把每張圖做成學習遊戲的「圖解」步驟（diagram）。

要求：
1. 找出圖中所有和【我的設定】主題有關的構造，依重要性選 5～15 個做標記。
2. 每個標記：name（中文名＋英文名）、desc（1～3 句：位置、相鄰構造、功能、神經血管或臨床重點）、x、y（標記點在圖片中的位置，以圖片寬高的百分比表示，0～100，左上角 0,0；點要落在構造本身）。
3. 仔細看圖後逐點估計座標，估完再逐一檢查一次；真的無法判斷的填 null（學生會在遊戲中自己點出位置）。
4. 如果圖上已經印有文字標籤，在回覆中提醒我「測驗前建議遮住標籤」。

輸出一個 JSON 程式碼區塊（合法 JSON，不能有註解），格式如下；圖片檔名請用我上傳的原檔名：
```json
{
  "schema": "xd-bundle/1",
  "packs": [
    {
      "schema": "xd-learn/1",
      "id": "（單元id，小寫英數與 -）",
      "subject": "（科目 id）",
      "path": ["（分類）"],
      "title": "（標題）",
      "lessons": [
        {
          "id": "l1",
          "title": "（課名）",
          "steps": [
            { "type": "intro", "title": "……", "body": ["這課要認識……"] },
            { "type": "diagram", "title": "……", "body": "……", "img": "（原檔名，例如 heart-front.png）", "mode": "both", "points": [ { "name": "……", "desc": "……", "x": 40.5, "y": 22 } ] },
            { "type": "recap", "points": ["……"], "flash": [ { "front": "……", "back": "……" } ] }
          ]
        }
      ]
    }
  ]
}
```
把圖片和這個 JSON（整段回覆存成 .md 也可以）放在同一個資料夾，就能導入。

【我的設定】
科目與 id：（例如：解剖學，anat）
主題：（例如：心臟前面觀）
單元 id 與分類：（例如：anat-heart，["解剖學", "心血管"]）
````

## 5-C 看圖辨識的題庫題目

````text
請用我上傳（或你找到的開放授權）圖片，出「看圖辨識」題目，做成學習遊戲的題庫。

規則：
- 每題用一張沒有文字標籤的圖，用 marks 在圖上標出編號：[{ "x": 35.5, "y": 42, "label": "1" }, { "x": 60, "y": 30, "label": "2" }]，x、y 是圖片寬高的百分比（0～100，左上角 0,0），點落在構造上。
- 題幹問「圖中編號 2 的構造是？」「編號 1 的肌肉由哪條神經支配？」「編號 3 受損時最可能出現？」等；選項 4 個，誘答用相鄰或容易混淆的構造。
- 同一張圖可以出多題，每題問不同編號或不同面向（名稱、功能、支配、臨床）。
- answer 寫字母；explain 寫：構造名稱（中英）、位置與辨識線索、正確答案的理由、每個錯誤選項是哪個構造或錯在哪。
- 無法確定座標時不要寫 marks，改在【需要確認】列出每題需要在圖上標註的位置說明。
- 圖片路徑：img/<題本id>/<檔名>；找網路圖時附【圖片清單】（檔名｜直接圖檔網址｜作者｜授權）。

輸出格式（合法 JSON，不能有註解）：
```json
{
  "schema": "xd-bundle/1",
  "subjects": [ { "id": "anat", "name": "解剖學", "theme": "sci" } ],
  "sets": [
    {
      "schema": "xd-bank/1",
      "set": { "id": "anat-upper-limb-img", "subject": "anat", "name": "上肢看圖辨識", "path": ["解剖學", "第5章 上肢"] },
      "questions": [
        { "n": 1, "type": "single", "stem": "圖中編號 2 的肌肉是？", "img": ["img/anat-upper-limb-img/shoulder-post.png"], "marks": [ { "x": 38, "y": 30, "label": "1" }, { "x": 55, "y": 44, "label": "2" } ], "choices": ["棘上肌", "棘下肌", "小圓肌", "大圓肌"], "answer": "B", "explain": "……", "tags": ["旋轉肌袖"] }
      ]
    }
  ]
}
```
你能建立檔案時把 JSON 與圖片打包成 zip；不能時先寫「檔名：<題本id>.json」再用 ```json 區塊輸出。

【我的設定】
科目與 id：（例如：解剖學，anat）
範圍與題數：（例如：上肢肌肉，30 題）
````

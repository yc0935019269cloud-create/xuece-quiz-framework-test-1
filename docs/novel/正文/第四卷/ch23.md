# 第二十三章　剖眼

聞止的手停在半夏臉側，許久沒有出聲。

烏梅伏在他膝上，尾巴慢慢掃過他的衣袖。遠處有人收起竹匾，匾沿碰撞，發出兩聲輕響；藥圃裡的水仍在流，像什麼也沒有聽見。

半夏等著他問。問她知道多少，是誰告訴她的，又或者，問一問她聽見蘇蘅的名字時，心裡在想什麼。

聞止收回手，扶住桌沿站起身。

「明日讓你外婆考你。」

他摸到廊柱，沿著熟悉的路往竹屋去。走到簷角，他用手背碰了碰垂下的竹簾，避開簾鉤，再跨過門檻。烏梅被留在凳上，抬頭望著他的背影，叫了一聲。

半夏沒有叫他。

她坐到院裡的燈燃短了，才回屋。包花盆的布擱在枕邊，結是林婆婆打的，鬆緊恰好，提起來不會滑。她解開一次，又照原樣繫回去，繫得不如婆婆平整，便拆了重繫。

到第三次，她把布放下，躺在床上。竹窗外有蟲鳴，時近時遠；有人經過水渠，腳步在橋板上響了四下，停住，又響了四下。她以為是聞止來了，起身推窗，只看見阿禾抱著一隻空桶，蹲在渠邊打水。

「葉姑娘還沒睡？」

「水渠也沒睡。」

阿禾低頭看了看水，覺得很有道理，提著桶走了。

半夏把窗合上，仍睡不著。聞止說那兩個字時，語氣平靜得像在說明日吃什麼。她卻在心裡將那兩個字翻來覆去，想起林婆婆切藥時的刀，想起老人把栗子連籃接過去，又想起她指尖摸過盆上的「蘅」字。

原來那是蘇蘅的母親。原來她見到自己揀藥的手，會怔住，並非因為手法有什麼稀奇。

半夏把手放在被上，看了很久。這雙手是聞止教的，他握著她的手腕，教她扶穩藥材，教她落刀時別只顧著快。他從不說這些手勢從何處學來；如今她知道了其中一部分，剩下的，他還是不肯說。

她想去問，又想起他昨夜站起身時扶桌的樣子。那人能聽出竹匾裡有幾片碎葉，能摸著她手背上幾乎看不見的傷，卻不肯聽她問完一件舊事。

天快亮時，屋外傳來掃地聲。半夏索性起身，洗過臉出門，見林婆婆正在廊下晾乾淨的布，布角一個壓著一個，連垂下的長短也差不多。

「睡了嗎？」老人問。

「睡不著。」

「那先吃飯。」

「您不問為什麼？」

林婆婆將最後一塊布掛好：「你師父昨夜走出來，我便知道了。」

半夏等她往下說，老人卻只將一碗粥放在桌上，又推來一碟醃菜。她餓了一夜，粥端起來時還有些燙，喝了兩口，才想起自己原想先問聞止去了哪裡。

「在東屋。」林婆婆道，「他吃過了。」

半夏看著她。

「你方才朝東屋看了三回。」

她低頭喝粥。林婆婆等她吃完，遞給她一塊擦手的布：「跟我來。」

---

刀房在藥圃北邊，窗朝東，晨光剛好落進來。

半夏進門，先聞到洗淨木案後的淡淡水氣。屋裡乾淨得像佛堂，牆上沒有畫，也沒有多餘的飾物；一架刀從小到大排開，刀身擦得發亮，刀柄全朝同一邊。案旁搭著白布，每塊都折成方正的四疊，底下放著清水與器皿。

門外有響動。栗子從木箱裡出來了，沿著曬暖的石階慢慢走，糯米跟在旁邊，走兩步便停下來等牠。兩隻最後趴在刀房門口，一隻白，一隻褐，正好各佔一塊有陽光的磚。

烏梅見了，也想擠進那塊日光。牠先嗅糯米的耳朵，糯米動了動，沒有走；牠又把鼻尖湊向栗子，忽地向後一縮，接連打了兩個噴嚏。

栗子把頭埋低，只露出一片刺。烏梅抬爪按住鼻子，坐在門外，十分惱怒地望著牠。糯米趁牠不動，慢慢挪過去，佔了牠剛才站的地方。

林婆婆看了一眼，將門虛掩，留兩隻小獸在外頭曬太陽。她在案上放好一顆羊眼，又取刀、布與盛水的器皿，一樣一樣擺定，連半夏站的位置也用目光示意了。

「看清楚。」

她落刀。刀刃過處幾乎沒有聲響，手腕只動了一點，羊眼便順著她的力道慢慢分開。半夏屏住氣，看見切開的邊緣平滑，水光映在上面，薄薄一道，像新磨好的鏡面。

「你試。」林婆婆將刀遞給她。

半夏接刀，先穩住手邊的東西，再沿著已開的地方慢慢分離。刀尖碰到一處，她停下來，換了個角度，沒有硬切。

「為什麼停？」婆婆問。

「這裡薄。往下再使力，容易傷到裡頭。」

林婆婆沒有答，只將燈挪近些。半夏借光看清，才繼續動手。婆婆站在一旁，既不催，也不替她接過刀；半夏切完一段，她才伸手接住，將切面攤開。

「睫狀體在哪裡？」

半夏指出位置。林婆婆將刀尖移到外側，問：「由外到內，五層怎麼排？」

「睫狀體上層、基質、色素上皮、無色素上皮、內界膜。」

「血管與睫狀肌？」

「在基質。」

「哪一層朝著後房？」

「無色素上皮面向後房。」

林婆婆這才往下切。她不急著將東西分散，一邊剖，一邊把切下的部分按位置放好。半夏俯身看，屋外的風從窗邊經過，吹動她一縷頭髮；她騰不出手，林婆婆便替她將髮絲攏到耳後。

「你說得快。」老人道，「看見什麼，說什麼。」

半夏重新辨認一遍，把能看出的與需借細觀才能分辨的分開說。林婆婆聽她說到一處，刀忽然停了。

「你方才說，血管在色素上皮？」

半夏怔了怔。她剛才一心盯著眼前的層次，嘴上竟說錯了。

「基質。」她立刻更正，「血管與睫狀肌在基質。」

「錯了便重看。」

半夏想說自己只是說快了，見刀仍停著，終究沒說。她把各層的位置從外向內再走一遍，說到基質時放慢了些，確認沒有混淆。林婆婆這才重新動刀。

門外傳來輕輕的抓撓聲。烏梅不甘心被關在外面，白爪從門縫伸進來，撥了兩下；半夏看過去，林婆婆道：「先把眼前的看完。」

半夏收回目光。她從前以為考人總要擺出難題，今日才知道，林婆婆連她答過的也要她再看一次。刀不催人，停在那裡，倒比問話還叫人心裡發緊。

「這兩層上皮，隔著便不說話了？」婆婆問。

「兩層之間有間隙連結，讓兩層細胞互通消息。」半夏道，「無色素上皮細胞之間有緊密連結，參與血房水屏障。」

「哪兩處不同？」

「一處在兩層上皮之間，一處在無色素上皮細胞之間。」

林婆婆點了點頭。她用布擦過刀背，又換了一把更小的刀，刀柄仍朝向半夏伸手最容易拿到的一邊。

半夏望著那一排刀，忽然想起自己揀藥時將葉柄朝外。她昨夜想了一整夜，還是沒敢問：聞止教她的手勢，是不是蘇蘅也曾這樣教過他。

林婆婆察覺她的目光：「刀柄朝外，下一個人接刀，不必去碰刃。」

「葉柄朝外，也是為了下一個人。」

林婆婆取一塊細布鋪在案邊，讓她再練一次握刀。半夏將刀拿起，照著方才的位置落下，刀鋒卻在最後微微偏了。她抬頭看婆婆，老人沒有說話，只將一片薄薄的藥葉推到她面前。

「切斷它，別把下面的布割破。」

半夏試了兩次。第一回葉子斷了，布上留下一道淺痕；第二回刀停得早，葉柄還連著。她將葉子擺正，第三回才切開，拿起布看時，底下沒有傷。

「方才是刀的緣故？」林婆婆問。

「是我心急。」

「現在呢？」

「現在知道您不會替我把話說完。」

林婆婆從她手中取過布，看了看那道淺痕，將布摺起，沒有丟。半夏以為她還要再考，正要重拿一片葉子，她卻取回刀，示意半夏繼續看。

老人嗯了一聲，沒有放下刀。窗邊日光漸漸移到案上，照亮她手背的細紋；她切開最後一小處，邊沿依然平整，沒有一片多餘的碎屑。

---

林婆婆命半夏洗過手，將門打開透氣。日頭已升高，糯米換了個方向趴著，栗子仍在原處，身上的刺被曬得暖融融的。烏梅蹲在遠一點的台階上，背對牠們，假裝自己從沒想過要加入。

藥圃那頭忽然有人喊：「鄧伯！」

這一聲是阿禾喊的，聲音大得驚起籬上的灰灰。半夏循聲望去，只見鄧伯戴著一頂舊斗笠，正蹲在一畦草邊，兩手抱著一把新拔的雜草。他昨夜還躺著，如今眼前遮著布，卻已找到了地裡最難拔的一叢。

「我只是坐坐。」他說。

阿禾看了看他手裡的草：「草自己坐到您懷裡的？」

鄧伯不答，試圖把草藏到身後。那一把太大，藏了左邊露出右邊；他只好將它放回地上，還順手把草根上的土抖乾淨。

林婆婆站在刀房門前，沒有揚聲。鄧伯一抬頭看見她，先扶住斗笠，再慢慢站起來，像剛才蹲下不過是為了替它繫帶。

「我來看看。」他道。

「看完了？」

「看完了。」

「手上的泥呢？」

「路上扶了一把。」

「扶的草？」

鄧伯沉默片刻：「它倒了。」

半夏忍著笑，替他看過眼睛，又叫他跟著阿禾回屋休息。鄧伯走出幾步，回頭叮囑藥童把拔下的草帶走，別曬在地上，免得種子落回田裡。藥童抱起那一大把，走得東倒西歪，他又想伸手幫忙，林婆婆只望他一眼，他便把手縮回袖中。

小山坐在廊下，右眼仍護著，精神比昨日好些。他爹在旁削一根木杖，木屑落了一地；見鄧伯經過，趙大成忙起身讓路，鄧伯卻對著小山笑：「你可別學我。」

小山問：「學您下田？」

「學我被逮到。」

林婆婆道：「你們兩個，今日都不許離開院子。」

鄧伯與小山相互看了一眼，誰也沒再說話。阿禾把一張矮桌搬到兩人中間，給他們擺了茶，還將一碟剝好的豆子放在小山左手邊。趙大成見兒子能自己取食，便把木杖削得更圓了些。

鄧伯摸到碟子，撿起一顆豆，問小山昨日那頭鹿後來怎麼處置。小山說田二叔送去他家，還替他娘劈了一捆柴。趙大成聽了，刀在木杖上停了一停，說等兒子好些，自己也要去田家一趟。

「去做什麼？」鄧伯問。

「把借他的繩還了。」

小山提醒他，繩是老周的，已經還了。趙大成耳根一紅，低頭繼續削木杖，木屑捲得比方才還長。鄧伯沒有拆穿，只把豆碟往小山那邊推近些。

半夏回刀房時，婆婆正在擦案。她把布浸過清水，沿木紋擦到底，再換一面，沒有來回抹。半夏取另一塊布幫忙，兩人一左一右，將案上收拾妥當。

「睫狀體有兩件差事。」林婆婆道，「一件你昨日說過，另一件是什麼？」

「睫狀突分泌房水；另一件是調節。」半夏拿起案邊的細繩，輕輕繃直，「看近時，睫狀肌收縮，懸韌帶放鬆，水晶體變凸。」

她鬆開指尖，細繩垂下。林婆婆看了看，將繩子捲好放回原處。

「睫狀肌裡的纖維呢？」

「縱走、放射、環狀三種。縱走纖維也叫布呂克纖維，環狀纖維也叫穆勒纖維。」

林婆婆問：「宮裡有人也叫穆勒？」

半夏先是一愣，隨即明白她問什麼：「周恆的眼瞼曾輕度下垂，我查他眼時見過眼瞼穆勒氏肌。睫狀肌的環狀纖維雖也叫穆勒，和眼瞼穆勒氏肌不是同一條。」

那個名字一出口，她想起井邊的採薇，想起秦姑姑藏在暗格裡的蟲形錢。許多事一頭連著另一頭，走到百草谷，仍沒有斷。

林婆婆見她出神，沒有追問，只取來一張紙，用炭筆畫了幾道簡單的線。半夏接過筆，把縱走、放射與環狀的位置分別指出，又在旁邊寫下名字。婆婆看過，將紙摺起，塞進她手裡。

「寫給我做什麼？」半夏問。

「你寫的，留著。」

「我記得住。」

「記得住也可以留著。」

半夏把紙收進袖中。她低頭時，瞥見婆婆將方才擦案的布折好，邊角壓得整整齊齊，和她昨夜替自己繫花盆的布一樣。

---

午飯後，林婆婆將羊眼重新放在燈下，問半夏房水從何而來。

「睫狀突造。」半夏道。

「怎麼造？」

半夏答：「主動分泌、超濾與擴散。主動分泌為主。」

「光憑一個『主動』，水便肯走？」

「要燒力氣。」半夏道，「後世叫這份力氣三磷酸腺苷。鈉鉀幫浦與碳酸酐酶參與離子搬運，水跟著滲透梯度走。」

林婆婆拿起一旁兩隻空碗，將一隻推近，另一隻留在遠處：「若把這裡當作有人搬東西的地方，你如何說？」

「人先費力將東西搬過去，水再順著形成的滲透梯度走。超濾與擴散也是房水生成的途徑，但主動分泌是主要的一條。」

「很好。昨日鄧伯的水出不去，今日小山的水漏了，你可別把造水和排水混在一處。」

「您昨日都聽見了？」

「廊下只有那麼大。」

半夏想起自己拿竹籤算時辰，還把涼茶倒進盆裡。她正想問婆婆有沒有聽見田老二後來送棗，屋外便傳來木劍相擊的一聲脆響。

兩人向窗外望去。鍾離霜與陸沉舟在空地上比試，長劍與刀都收了，換成兩根削平的木枝。鍾離霜一劍刺出，陸沉舟側身避開，木枝輕點她腕間，她立即收手，反轉劍勢，又從另一側攻去。

鐵翎立在架上，傷翅收攏，跟著兩人的動作轉頭。灰灰停在更高的竹竿上，離牠遠遠的。鍾離霜退到水渠邊，腳跟將碰上石沿，忽然笑道：「這次你總不能說我先動手了。」

「是你先拔的木枝。」陸沉舟道。

「木枝長在地上，誰先拔便算誰贏？」

「那你贏了。」

「再來。」

他們又過了幾招。陸沉舟一枝壓住她的劍，卻沒有往前逼；鍾離霜順勢抽身，抬足踢起地上的一片竹葉。陸沉舟閃過，竹葉輕飄飄落在他肩上。

「中了。」她道。

「是葉子。」

「葉子也是我的招。」

陸沉舟取下竹葉，放到她劍尖上。鍾離霜一抖手腕，葉子便飛進水渠，兩人同時收勢，誰也沒再爭。她拿起水壺先喝一口，又遞給他；他接過時說了聲多謝，兩人便坐在樹蔭下歇息。

半夏看得出神，林婆婆輕敲案沿：「看完了？」

「看完了。」

「兩條血管在前部會合，你也看完了？」

半夏立即回頭：「長後睫狀動脈與前睫狀動脈在睫狀體前部會合，形成虹膜大動脈環。」

「名字容易說，位置呢？」

半夏借紙上的眼圖指出睫狀體前部，再將兩條血管的名字分別寫在旁邊。林婆婆沒有急著接筆，待她說明白兩者的去處，才在會合處輕點一下。

「刀拿來。」

半夏將刀遞過去，刀柄朝向婆婆。老人接住，手指穩穩合攏，忽然停了一瞬。

半夏察覺了：「怎麼了？」

「你扶刀的手，和她很像。」

這回半夏沒有問是哪個她。林婆婆將刀放回架上，隔了一會兒，又取下來，用乾布重新擦了一遍。她擦得很慢，擦完才讓半夏把分開的東西收好，免得久置。

東屋窗下傳來棋子落盤的聲音。聞止與裴照坐在兩側，棋盤邊有一道淺淺的框，聞止以指尖辨認棋位，裴照落子後也會報出位置。元宵蜷在裴照腳邊，尾巴蓋住鼻尖，灰灰不知何時飛來，停在窗框上看他們。

半夏經過時，正聽見裴照道：「這一步，先生不救麼？」

聞止摸了摸棋盤，指尖停在一枚棋子旁：「你若再讓，我便不客氣了。」

「學生哪敢。」

「嘴上不敢，手倒敢。」

裴照笑了一聲，落下棋子。聞止伸手沿著盤面辨過，取起一子放下，裴照望著棋局，半晌沒有動。

「先生贏了。」他道。

「你母親下棋也這樣讓人。」

裴照一愣。窗外的風將他袖角吹起，他按住衣袖，問：「先生見過我母親？」

聞止卻在收棋，把棋子一枚枚摸回盒中。裴照伸手幫他，他聽見聲響，便把手移開，讓出一邊。

「我記錯了？」聞止問。

裴照看著他，沒有立即回答。半夏在門外站了一會兒，兩人都沒有再說話，只剩棋子落進盒裡，清脆地響。

元宵醒過來，抬頭嗅了嗅桌上的棋盒，想把鼻子伸進去。裴照輕輕攔住，牠便將下巴擱在他的鞋上，仍盯著那只盒子。聞止聽見指甲碰地的聲音，問是不是狐狸；裴照說是，又托起元宵的爪，讓他摸了摸。

「牠和烏梅常打架？」聞止問。

「為了一塊魚乾，可以爭半日。」

「誰贏？」

「看魚乾在誰手裡。」

聞止笑了笑。裴照也笑，手卻仍停在棋盒邊，指尖壓著盒蓋。他往門外望時，半夏已退到廊柱後，讓出窗下的光；過了一會兒，他才將蓋子合上，抱起元宵。

---

傍晚，刀房的光暗下來，林婆婆仍沒有叫半夏走。

她把刀一把把洗淨、擦乾，按大小放回架上。半夏替她收器皿，將布洗過，擰乾，搭在門邊。栗子已回了木箱，糯米趴在箱外，耳朵蓋著半隻眼；烏梅在稍遠處舔爪，鼻尖受了一刺之後，暫時不肯再靠近。

「今日考完了？」半夏問。

「你想走？」

「我想知道有沒有答錯。」

「有。」

半夏等著她指出哪一處，林婆婆卻先將屋子最後一角擦淨，才說：「你說快了，把基質說成色素上皮。後來改對了。」

「您記了一下午？」

「我還記得你自己改了。」

半夏看著她，忍不住笑了一下。她一笑，昨夜沒有睡的疲倦便浮上來，靠著門框站了一會兒。林婆婆取水給她，又往屋外看了看，確定沒有人等著，才走回刀架前。

架子最高處放著一只窄木匣，半夏白日只顧看刀，沒有留意。婆婆伸手取下木匣，放在案上，開蓋時動作很輕。裡頭是一把小刀，刀身擦得乾淨，柄上纏著褪色的紅線，線頭藏在刀柄末端。

「這把刀，蘇蘅十二歲第一次剖眼時用的。」

半夏沒有伸手。林婆婆將刀取出，橫放掌心，刀柄朝著她。

「她剖得沒你穩。她手快，心也快。」

「切壞了？」

「第一刀切歪了。她怕我看見，把眼睛轉了個方向，以為這樣我就不知道。」

「您知道？」

「她轉的時候，碰翻了水碗。」

半夏看著那把刀，眼前彷彿有個十二歲的姑娘，站在同一張案前，手忙腳亂地扶碗。她想問蘇蘅長得什麼樣，問她犯了錯會不會像自己一樣嘴硬，又覺得這些話太多，一時不知從哪一句開始。

「她後來呢？」

「把水擦乾，再切一回。第二回慢了些。」林婆婆道，「切完問我，若碰翻的是藥，會不會罰她。她嘴裡問著，手已經把碗拿到案子最裡面。」

「您罰了麼？」

「叫她把布洗乾淨。」

「那不算罰。」

「她洗完，又把我掛好的布全換了個方向，說這樣風容易吹到。」

林婆婆說到這裡，眼角浮起一點極淡的笑。半夏想起今早廊下的布角，忽然道：「所以您現在都自己掛？」

「她走以後，沒人再替我換方向。」

屋裡安靜下來。窗邊日光移開了，刀上的紅線不再鮮亮，只剩多年摸過留下的柔軟色澤。半夏伸手接過，刀比她想的輕，柄上纏線的地方恰好貼著她的掌心。

「給我？」

「給你。」

「這是她用過的。」

「我知道。」

半夏握著刀，沒有立刻收起。她想起溫硯交給她的花盆，也想起聞止將梅子包放進她手裡時，紙上殘留的暖意。這幾日她從旁人口中一點點認識蘇蘅，每知道一件，心裡便多出一處想問的地方。

「她拿這把刀，會不會也把柄朝外？」

「會。」林婆婆道，「她先學的這個。後來去教別人，也先教這個。」

半夏抬頭：「聞止呢？」

「他也學過。」

原來師父握住她的手，一遍遍教的事，在更早以前，已有另一雙手教過他。她把刀轉過來，像白日遞刀給婆婆時那樣，讓刀柄朝向對方。

「我若弄壞了呢？」

「刀是給人用的。」林婆婆把她的手輕輕推回去，「用完擦乾，收好。真壞了，拿回來給我看。」

半夏低頭應了一聲，將小刀放回木匣。她扣上匣蓋，試了試，確定不會鬆開，才抱在懷裡。林婆婆取燈時，她仍站在原地，像有話要說。

「還有什麼？」婆婆問。

半夏張了張口。那個稱呼在心裡已經念過許多次，到了嘴邊，卻比刀房裡最細的一道縫還難跨。

林婆婆沒有催。她提起燈，替半夏照著門檻，等她跨出去，才隨手將門掩上。

「外婆。」

老人手中的燈穩穩亮著，沒有晃。她回過頭，看向半夏。

「嗯。」

半夏抱緊木匣：「明日的布，我替您掛。」

「好。」林婆婆道，「別全換了方向。」

半夏笑了。藥圃那頭，聞止正坐在廊下等飯，聽見她們過來，將身旁的凳子往外挪了挪。林婆婆走在前面，燈光照著石路；半夏跟在後面，手掌貼著匣中的刀柄，走得很慢。

# 題庫格式規格 `xd-bank/1`

題目放在 `content/bank/<科目id>/` 底下，**一個檔案＝一個題本**（一章、一回試卷、一份講義的習題都可以）。支援兩種寫法：

- **JSON**：功能完整（題組文章、圖片、Markdown、多行詳解）。AI 產生題目時建議用這個。
- **CSV**：用 Excel／Google 試算表編輯後「另存 CSV UTF-8」。適合大量單字、是非、簡單選擇題。

放好後在框架根目錄執行：

```bash
python tools/build.py
```

會檢查每一題（答案格式、選項數、題號重複、圖片是否存在…），沒問題就輸出 `data/bank.js`。有錯的檔案整個略過並列出錯在哪。

## 1. 先在 `content/project.json` 登記科目

```jsonc
{
  "id": "bio-g10",                 // 專案代號＝存檔代號（小寫英數、_、-）。不同題庫用不同 id，存檔才不會互相覆蓋
  "title": "高一生物刷題地牢",       // 遊戲標題
  "subtitle": "一句話介紹",
  "disclaimer": "詳解為自編教學解說，僅供參考。",   // 選填：顯示在每題詳解下方
  "subjects": [
    {
      "id": "bio",                 // 科目 id：小寫英數與 _，也是 content/bank/ 底下的資料夾名
      "name": "生物",
      "theme": "sci",              // 區域主題（決定地區名、首領、怪物名前綴），見下表
      "desc": "細胞、遺傳、生態",    // 選填
      "color": "#5fe0d0",          // 選填，#RRGGBB
      "region": "生命之森",         // 選填，自訂地區名（不填就用主題預設）
      "words": ["細胞", "酵素", "基因"],  // 選填，怪物名字前綴（「細胞史萊姆」）
      "time": 90                   // 選填，限時作答秒數（預設：數理類 150、其他 75）
    }
  ]
}
```

| theme | 預設地區 | 適合 |
|---|---|---|
| `lit` | 墨韻書林 | 國文、作文、文學、閱讀 |
| `lang` | 異語迷城 | 英文、日文等外語 |
| `math` | 數理深淵 | 數學、邏輯、程式 |
| `calc` | 算式礦坑 | 統計、會計、商用數學、證照計算 |
| `hist` | 史地遺跡 | 歷史、地理、公民、法律、管理 |
| `sci` | 元素洞窟 | 物理、化學、生物、地科、醫護 |
| `mix` | ○○迷宮 | 不確定就選這個：首領從所有主題隨機登場 |

## 2. JSON 題本

```jsonc
{
  "schema": "xd-bank/1",
  "set": {
    "id": "bio-ch1",              // 題本 id（英數、_、-），全專案唯一。題目 id 會是「題本id-題號」
    "subject": "bio",             // 省略時用資料夾名
    "name": "第1章 細胞",          // 顯示名稱
    "year": 2025,                 // 選填（歷屆試題可填年度，會顯示在名稱前）
    "order": 1,                   // 選填，同科目內排序
    "source": "某某講義 p.12-20",  // 選填，顯示在詳解下方
    "source_url": "../講義/ch1.pdf"   // 選填，詳解旁出現「開啟原始資料」按鈕
  },
  "groups": [                      // 選填：題組（共用一段文章／圖表）
    { "id": "g1", "title": "閱讀：細胞膜實驗", "text": ["文章第一行", "第二行"], "img": ["img/bank/bio-ch1/g1.png"] }
  ],
  "questions": [ /* 見下 */ ]
}
```

### 題目共同欄位

| 欄位 | 說明 |
|---|---|
| `n` | 題號（整數，題本內不可重複；省略時依順序 1, 2, 3…） |
| `type` | `single` 單選、`multi` 多選、`tf` 是非、`fill` 填答、`open` 非選（申論／計算過程／寫作，自評） |
| `stem` | 題幹（Markdown，可寫成字串陣列一行一個元素） |
| `img` | 選填，題目圖片路徑陣列（以框架根目錄為準，建議放 `img/bank/<題本id>/`） |
| `explain` | **詳解**（Markdown）。答錯時自動顯示，是學習的關鍵 |
| `tags` | 標籤／考點陣列（用於搜尋、學習模式抽題）。**要用學習課程裡實際教的名詞**：學習單元宣告 `banks` 後，一題的所有 tags 都必須在課程（或該課的 `teaches`）出現過才會被抽到，見《格式_學習模式》§9 |
| `level` | 選填，難度 1 基礎、2 標準、3 進階 |
| `group` | 選填，所屬題組 id |

> `stem` 或 `img` 至少要有一個。**標籤會在作答後才顯示**，但仍不要把答案寫進標籤。

### 各題型

```jsonc
// 單選：answer 寫字母（或 0 起算的數字）
{ "n": 1, "type": "single", "stem": "……", "choices": ["甲", "乙", "丙", "丁"], "answer": "C", "explain": "……", "tags": ["……"] }

// 多選：answer 寫所有正確選項字母
{ "n": 2, "type": "multi", "stem": "……（多選）", "choices": ["…", "…", "…", "…", "…"], "answer": "ACE", "explain": "……" }

// 是非：answer 是 true / false（遊戲中顯示成 ⭕ 對／❌ 錯 兩個選項）
{ "n": 3, "type": "tf", "stem": "……", "answer": false, "explain": "……" }

// 填答（自動批改）：answer 是標準答案；accept 列出所有可接受寫法
{ "n": 4, "type": "fill", "stem": "水的化學式是 ____。", "answer": "H₂O", "accept": ["H₂O", "H2O"], "explain": "……" }

// 填答（改成自評）：accept 設成 false —— 答案不唯一時用
{ "n": 5, "type": "fill", "stem": "舉一個……的例子", "answer": "參考：……", "accept": false, "explain": "……" }

// 非選：answer 是參考答案，學生看完自評
{ "n": 6, "type": "open", "stem": "說明……", "answer": "參考答案……", "explain": "評分重點：……" }

// 選項在圖片裡（例如掃描的考卷）：不給 choices，改給 opts（選項數）
{ "n": 7, "type": "single", "img": ["img/bank/exam-2024/q7.png"], "opts": 5, "answer": "B", "explain": "……" }
```

**填答自動批改規則**：忽略空白、全形／半形、大小寫、上下標（`H₂O` = `H2O`、`x²` = `x2`）、句尾標點；兩邊都是數字或分數時比數值（`10/18` = `5/9`、`１００` = `100`）。其他寫法（單位、同義詞、`0.5` 與 `50%`）要自己列進 `accept`。

## 3. CSV 題本

第一列是欄名（大小寫不拘，沒用到的欄可以不放）。**檔名＝題本名稱，所在資料夾＝科目 id**。

| 欄名 | 說明 |
|---|---|
| `n` | 題號 |
| `type` | single / multi / tf / fill / open（空白時：有選項＝single，沒選項＝open） |
| `stem` | 題幹（要換行寫 `\n`） |
| `a` ~ `j` | 選項 A ~ J |
| `answer` | 單選 `B`、多選 `ACD`、是非 `對`/`錯`（或 true/false、O/X）、填答標準答案、非選參考答案 |
| `accept` | 填答的其他可接受寫法，用 `|` 分隔 |
| `explain` | 詳解（換行寫 `\n`） |
| `tags` | 標籤，用 `|` 或頓號分隔 |
| `img` | 圖片路徑，用 `|` 分隔 |
| `level` | 1 / 2 / 3 |

範例：`content/bank/demo_eng/vocab-basic.csv`。Excel 存檔時選「**CSV UTF-8（逗號分隔）**」，不然中文會變亂碼。
CSV 不支援題組（需要題組請用 JSON）。檔名是中文時，題本 id 會用檔名自動產生一組代號——**之後不要再改檔名**，不然作答紀錄會對不上。

## 4. 數學式、化學式怎麼寫

遊戲是離線的，**不支援 LaTeX**。用 Unicode：`x²`、`x³`、`xⁿ`、`a₁`、`√2`、`π`、`∞`、`∩ ∪ ⊂ ∈`、`≤ ≥ ≠ ≈`、`×  ÷  ±`、`→ ⇒ ⇔`、`Σ`、`θ`、`Δ`、`°`、`H₂O`、`SO₄²⁻`、`⇌`；分數寫 `a/b`；重要算式放在 ```` ``` ```` 程式碼區塊。複雜的圖形或公式就截圖放 `img`。

## 5. 題目 id 與存檔

- 題目 id＝`題本id-題號`（例：`bio-ch1-12`）。**改題本 id 或題號，作答紀錄就對不上**（會當成新題）；修改題目內容、答案、詳解則不影響紀錄。
- `python tools/build.py --index` 會產生 `content/_index/<科目>.tsv`（題號、題型、標籤、題幹與詳解開頭），給 AI 挑題、連結學習模式用。

## 6. 新增功能（v2）

- **不必建置也能加題目**：營地「📥 導入素材」選資料夾，會自動辨識 JSON、CSV、AI 回覆存成的 .md（抓裡面的 ```json／```csv 區塊）、整包 `xd-bundle/1`，並判斷科目與年份，確認後存在瀏覽器（IndexedDB）。
- **CSV 中文欄名**：題號、題型、題目、選項A～J、答案、可接受答案、詳解、標籤、圖片、難度，以及每列可不同的「年份、科目、題本」（同一檔會依這三欄自動分成多個題本）。題型可寫中文（單選、多選、是非、填答、非選）。
- **寬鬆的答案寫法（導入時）**：`(B)`、`B、D`、`②④`、`Answer: C and D`、`○`／`錯` 等都會自動轉換；選項前的 `(A)`、`1.` 標號會自動移除。
- **圖片編號標記 `marks`**：`[{ "x": 35, "y": 42, "label": "1" }]`，疊在題目第一張圖上（x、y 為百分比）；題組也可用 `marks`。
- **分類 `set.path`**：選填，例如 `["學測歷屆", "英文"]`。
- **混合題題號**可以是字串，例如 `"20-1"`。
- 詳解中出現「答案存疑」時，建置與導入都會提醒。

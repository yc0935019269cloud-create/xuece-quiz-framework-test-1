## 58張卡的手寫念法

ch｜tag｜zy｜how

| ch | tag | zy | how |
|---|---|---|---|
| ㄱ | 子音 | ㄍ | 像注音ㄍ但更輕，字首介於ㄍ和ㄎ之間；收尾只擋住不放開。 |
| ㄴ | 子音 | ㄋ | 舌尖往上貼住上排牙齒後面的牙齦，念起來就是注音ㄋ。 |
| ㄷ | 子音 | ㄉ | 舌尖頂住牙齦再放開，字首介於ㄉ和ㄊ之間；收尾擋住不放開。 |
| ㄹ | 子音 | ㄌ | 字首像很輕的ㄌ，舌尖彈一下；字尾舌尖貼住，氣從兩側出去。 |
| ㅁ | 子音 | ㄇ | 上下嘴唇閉緊，讓聲音從鼻子出來，念起來就是注音ㄇ。 |
| ㅂ | 子音 | ㄅ | 嘴唇先閉住再放開，字首介於ㄅ和ㄆ之間；收尾閉住不放開。 |
| ㅅ | 子音 | ㄙ | 像ㄙ，氣從牙縫擦出；接ㅣ像ㄒ，收尾則做ㄉ的嘴型但不放開。 |
| ㅇ | 子音 | ∅／ㄥ | 放在字首只佔位、不發音；放在字尾才念ㄥ，像ㄤ的尾巴。 |
| ㅈ | 子音 | ㄐ | 像注音ㄐ，在牙齒附近先擋一下再擦出去；收尾做ㄉ的嘴型不放開。 |
| ㅊ | 子音 | ㄑ | 像注音ㄑ，放開時多吐一大口氣；收尾做ㄉ的嘴型但不放開。 |
| ㅋ | 子音 | ㄎ | 舌根頂住上顎後面，放開時多吐一口氣，像ㄎ；收尾像ㄍ不放開。 |
| ㅌ | 子音 | ㄊ | 舌尖頂住牙齦，放開時多吐一口氣，像ㄊ；收尾像ㄉ但不放開。 |
| ㅍ | 子音 | ㄆ | 嘴唇閉住，放開時吐一大口氣，像注音ㄆ；收尾嘴唇閉住不放開。 |
| ㅎ | 子音 | ㄏ | 氣直接從喉嚨呼出，像更輕的ㄏ；在兩個母音中間常輕到快聽不見。 |
| ㄲ | 子音 | ㄍ 緊 | 舌根擋住，喉嚨繃緊，幾乎不吐氣，念得像又緊又硬的ㄍ。 |
| ㄸ | 子音 | ㄉ 緊 | 舌尖頂住牙齦，喉嚨繃緊、不吐氣，像很用力的ㄉ，不放在字尾。 |
| ㅃ | 子音 | ㄅ 緊 | 嘴唇閉緊、喉嚨繃緊，放開時不吐氣，像用力的ㄅ，不放在字尾。 |
| ㅆ | 子音 | ㄙ 緊 | 氣從牙縫擦出，比ㄙ更緊更尖；放字尾時做ㄉ的嘴型但不放開。 |
| ㅉ | 子音 | ㄐ 緊 | 像很用力的ㄐ，念的時候不吐氣；這個字母不會放在字尾。 |
| ㅏ | 母音 | ㄚ | 嘴巴張大，像注音ㄚ；要把它寫成一個字，前面配上不發音的ㅇ。 |
| ㅑ | 母音 | ㄧㄚ | 先輕輕滑過ㄧ，再接著念ㅏ的ㄚ，連起來就是近似ㄧㄚ的聲音。 |
| ㅓ | 母音 | ㄛ 張大 | 像ㄛ但嘴巴張大，嘴唇放鬆不要圓，有一點接近ㄜ，別和ㅗ混了。 |
| ㅕ | 母音 | ㄧㄛ 張大 | 先滑過ㄧ再念ㅓ，像ㄧㄛ，但嘴唇要放鬆，不要把嘴唇圓起來。 |
| ㅗ | 母音 | ㄛ 圓唇 | 嘴唇圓起來、往前嘟，像注音ㄛ但更圓，和嘴唇放鬆的ㅓ不同。 |
| ㅛ | 母音 | ㄧㄛ 圓唇 | 念起來像ㄧㄛ，前面先帶過ㄧ，接著念嘴唇圓起來的ㅗ。 |
| ㅜ | 母音 | ㄨ | 嘴唇圓起來，往前嘟成一個小圓孔，念起來就像注音ㄨ。 |
| ㅠ | 母音 | ㄧㄨ | 像ㄧㄨ，念的時候嘴唇要一直圓，注意不要把它念成ㄧㄡ。 |
| ㅡ | 母音 | ㄜ 扁唇 | 嘴角往兩邊拉平、舌頭平放，發出像ㄜ的悶聲；嘴唇不圓，不是ㄨ。 |
| ㅣ | 母音 | ㄧ | 舌頭往前上方抬，嘴角拉開，念起來就像注音ㄧ的聲音。 |
| ㅐ | 母音 | ㄝ | 像ㄝ，嘴巴比ㅔ稍微張大；現代首爾話兩者幾乎一樣，要靠拼字記。 |
| ㅒ | 母音 | ㄧㄝ | 先帶一個ㄧ，再接ㅐ的聲音，像ㄧㄝ；這個母音比較少見。 |
| ㅔ | 母音 | ㄝ | 像注音ㄝ，嘴巴比ㅐ小一點點；現代口語中兩者聽起來幾乎一樣。 |
| ㅖ | 母音 | ㄧㄝ | 像ㄧㄝ，先帶過ㄧ；前面有子音時，常常會念得像ㅔ的ㄝ。 |
| ㅘ | 母音 | ㄨㄚ | 先圓唇念ㄛ，馬上滑到ㄚ，兩個聲音連起來就像注音ㄨㄚ。 |
| ㅙ | 母音 | ㄨㄝ | 由ㅗ和ㅐ合起來，念起來像ㄨㄝ；例字왜本身就是為什麼。 |
| ㅚ | 母音 | ㄨㄝ | 寫法像ㄛ加ㄧ，現代多半念ㄨㄝ，和ㅙ、ㅞ聽起來很像。 |
| ㅝ | 母音 | ㄨㄛ | 先圓唇念ㄨ，再滑到ㅓ的ㄛ，連起來像ㄨㄛ，是ㅜ加ㅓ。 |
| ㅞ | 母音 | ㄨㄝ | 由ㅜ和ㅔ合起來，念起來像注音ㄨㄝ，這個寫法多用在外來語。 |
| ㅟ | 母音 | ㄨㄧ | 像注音ㄨㄧ，從ㄨ很快地滑到ㄧ，兩個聲音要連著滑過去。 |
| ㅢ | 母音 | ㄜㄧ | 字首先扁唇念ㄜ再滑到ㄧ；前有子音念ㄧ，當「的」用時常念ㄝ。 |
| ㄱ | 收尾音 | (ㄍ) | 寫在下面時舌根抬起擋住氣流，嘴型停住不放開；ㅋ、ㄲ也這樣收。 |
| ㄴ | 收尾音 | ㄢ | 寫在下面時，舌尖貼住上牙齦，讓聲音從鼻子出來，收成ㄴ。 |
| ㄷ | 收尾音 | (ㄉ) | 寫在下面時舌尖抵住上牙齦，停住不放開；ㅅ、ㅈ等也收成這個音。 |
| ㄹ | 收尾音 | ㄚ(ㄌ) | 寫在下面時舌尖貼住上牙齦停住，讓聲音從舌頭的兩側流出。 |
| ㅁ | 收尾音 | ㄚ(ㄇ) | 寫在下面時雙唇輕輕閉起來，讓聲音從鼻子出來，收成ㅁ。 |
| ㅂ | 收尾音 | (ㄅ) | 寫在下面時雙唇合起來，停住不放開；ㅍ寫在下面也收成同樣的音。 |
| ㅇ | 收尾音 | ㄤ | 寫在下面時舌根靠近上顎，聲音從鼻子出來成ㄥ，這時不是不發音。 |
| ㄳ | 收尾音 | (ㄍ) | 兩個一起寫在下面，單獨收尾念左邊ㄱ，聽例字結尾怎麼收住。 |
| ㄵ | 收尾音 | ㄢ | 寫在下面時，單獨收尾念左邊ㄴ，不是兩個都念，先聽例字尾音。 |
| ㄶ | 收尾音 | ㄢ | 兩個字母一起寫在下面，單獨收尾只念左邊ㄴ，對照例字聽收尾。 |
| ㄺ | 收尾音 | (ㄍ) | 寫在下面通常收右邊ㄱ；後面接ㄱ時改念左邊ㄹ，例如읽고。 |
| ㄻ | 收尾音 | ㄚ(ㄇ) | 寫在下面時單獨收尾念右邊ㅁ，先聽例字，注意結尾怎麼收住。 |
| ㄼ | 收尾音 | ㄚ(ㄌ) | 寫在下面通常收左邊ㄹ，但밟다是例外，要收成ㅂ，跟著例字聽。 |
| ㄽ | 收尾音 | ㄚ(ㄌ) | 兩個一起寫在下面，單獨收尾念左邊ㄹ，先聽例字結尾的收法。 |
| ㄾ | 收尾音 | ㄚ(ㄌ) | 寫在下面時，單獨收尾只念左邊ㄹ，兩個字母不用各念一次。 |
| ㄿ | 收尾音 | (ㄅ) | 寫在下面單獨收尾念右邊ㅍ，實際收成ㅂ音，雙唇合起來不放開。 |
| ㅀ | 收尾音 | ㄚ(ㄌ) | 寫在下面單獨收尾念左邊ㄹ，先聽例字，注意結尾如何停住。 |
| ㅄ | 收尾音 | (ㄅ) | 兩個一起寫在下面，單獨收尾念左邊ㅂ，跟著例字聽結尾怎麼收。 |

# 背景商店與營地布置（設計規格）

營地的「🛍 背景商店」：用魂晶直接買物件／場景，或在卡池抽獎。抽到的物件累積碎片，同一件達到數量才解鎖；可以把物件放進營地、拖曳移動。

## 素材（`assets/decor/`）

- 正本清單：`assets/decor/manifest.json`（格式見下）。`python tools/decor_data.py` 把它轉成 `js/decor-data.js`（`window.DECOR_DATA`，file:// 不能 fetch JSON，所以要轉成 JS；不要手改）。
- 物件：`assets/decor/items/<id>.png`，透明背景、像素畫（邏輯像素整數倍放大、最近鄰）、四周留 2px 透明邊、底部貼齊物件的「腳」（放在地上時底邊＝地面）。
- 場景：`assets/decor/scenes/<id>.png`，1536×384（4:1），側視；畫面下方約 28% 是平坦地面（物件放在這一帶），中間偏下不要有大型障礙物，左右兩側可裁切（手機會裁到約中間 1/3～1/2）。不要文字、人物。
- 風格：和現有營地一致的像素畫（Kenney Tiny Dungeon 16px 圖塊、深色描邊 #2a1a28 左右、有限色盤、光從左上），側視／略俯視。

### manifest.json

```json
{
  "version": 1,
  "series": [{ "id": "cabin", "name": "木屋小窩", "desc": "…" }],
  "scenes": [{ "id": "scene_beach", "name": "海邊沙灘", "desc": "…", "file": "assets/decor/scenes/scene_beach.png", "ground": 0.28, "night": "dim" }],
  "items":  [{ "id": "cabin_stool", "name": "木頭小板凳", "desc": "…", "series": "cabin", "rarity": "N", "file": "assets/decor/items/cabin_stool.png", "w": 32, "h": 30, "px": [16, 15] }]
}
```

- `w`／`h`：桌機營地（高 250px）上建議顯示大小（CSS px），手機自動 ×0.72。勇者約 124px 高、寵物 66px。
- `px`：原圖邏輯像素大小（未放大前）。
- `ground`：場景地面帶占圖高的比例（從底部算）。
- `night`：`dim`（夜晚用濾鏡調暗）或 `self`（場景本身就是夜景／室內，不再調暗）。

## 經濟與機率

- 單抽 20 魂晶、十連 180 魂晶（十連保證至少一件 SR 以上）。
- 機率：雜物 12%、N 50%、R 27%、SR 9%、SSR 2%（同稀有度內平均）。場景算 SSR，和 SSR 物件平分 SSR 機率。
- 保底：每個卡池各自計數，連續 59 抽沒有 SSR，第 60 抽必中 SSR；抽到 SSR 歸零。
- 碎片解鎖：每抽一次得到該物件 1 片。解鎖（＝可放 1 件）所需碎片：N 3、R 3、SR 2、SSR 1、雜物 1。之後每再湊滿一份就多一件可擺放（可放的件數＝floor(碎片／需要數)）。場景 1 片就解鎖，重複抽到場景退 30 魂晶。
- 抽到雜物另退 2 魂晶（「有好有壞」）。
- 直接購買（商店「直購」分頁）：cabin／forest／academy 三系列的 N 與 R（N 40、R 90 魂晶，買一次＝一件，等同直接補滿一份碎片）；四個商店場景。SR／SSR 與 seaside／sakura／arcane 系列只能抽。
- 卡池：
  - `standard` 冒險者雜貨：cabin、forest、academy、junk、scene_library
  - `seasakura` 海風與櫻：seaside、sakura、junk、scene_island
  - `arcane` 星辰祕庫：arcane、junk、scene_crystal、scene_starobs

## 存檔（`Store.profile.decor`，隨 exportAll／雲端同步）

```js
decor: {
  ver: 1,
  shards: { cabin_stool: 4 },          // 累積碎片（含直購補的）
  scenes: ['classic', 'scene_beach'],  // 已擁有場景
  scene: 'classic',                    // 目前場景
  placed: [{ k: 'p1', id: 'cabin_stool', x: 0.62, y: 0.05, f: 0 }], // x＝左右 0～1（物件中心）、y＝距地面高度 0～1（相對地面帶）、f＝水平翻轉
  pity: { standard: 12 },              // 距上次 SSR 的抽數
  draws: 37, log: [ { t, pool, id } ]  // 最近 30 筆抽卡紀錄
}
```

舊存檔沒有 decor：補預設值即可（擁有 classic、什麼都沒擺）。

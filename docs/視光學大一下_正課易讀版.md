散光第一課沿用已認可的光斑互動：同束光在前／中／後呈直線／圓／橫線。模型的屈光度中點由薄透鏡幾何計算，非兩個焦線距離算術平均。其餘原有4個互動完整保留。

概念可連續多頁，`pace: "free"`；不新增一堆練習，不要求每卡後接題。表格樣式僅擴到01～09，不影響99名詞及其他科目。播放器、學習紀錄格式與題庫未因此修改。新增頁面會改變進行中存檔的頁序，建議回課頭重讀；沒有清除存檔。

## 完整性與內容更正

`s114_course_audit.py`逐課比對原正文、原重點、國考提醒、示範、導入、原題／範例／實戰、卡片與課程欄位。原文字只允許明列更正，不以縮短之名遺漏；原題幹、選項、卡片正面與ID保留。另核對非目標課，九堂總複習與99名詞逐欄不變。

原167題檢核、250張記憶卡保留；編譯後所有檢核／卡片ID與其他學習包相同，完整題庫除建置時間外亦相同。

106處欄位更正（同一觀念在正文、題解、重點、卡背重複時均同步）記在`tools/learn-redo/s114-course-corrections.json`，含before／after與欄位路徑。重點包括：

- PH改善是屈光因素線索；PH0.6不是「已排除屈光」或正式矯正必達0.6的保證。原題以可矯正潛力作簡化時，在題解說清原題意圖與實務限制，未改原選項答案。
- COLC是屈光度中點的圓形模糊光斑，不是兩焦線距離算術中點，也不等於已無散光。
- 調節幅度統一R為近視負、遠視正，AA＝1/NPA(m)＋R；不要混用另一套近遠點符號。
- MRP是major reference point，非「最大正鏡至最佳視力」。ADD前頂點法須遠近讀值同基準。
- 檢影是否扣WL看毛值／另放工作鏡是否已排除；不能只看有無戴鏡。平移鏡片順逆動與檢影回光不同。剪刀樣反射不能唯一等同球面像差。
- 直接／間接按照光眼命名，並非傳入／傳出的別名；III麻痺瞳孔可保留；Horner三個表現不是英文都以-osis結尾。
- horopter是對應網膜位置的空間軌跡，不是所有同距離的點；Frisby／Lang不需要特殊分圖鏡，但仍可需處方矯正。

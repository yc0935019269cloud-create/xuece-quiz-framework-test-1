# 世界觀設定（開發用，遊戲內不明說）

遊戲裡**不直接解釋**這些設定，只透過遺物故事、怪物圖鑑、首領介紹零碎地暗示。新增內容時請遵守「只暗示、不解釋」：用物件、遺留的痕跡和別人的話帶出來，不用旁白交代。文字寫在 `js/world.js`（`RELIC_LORE`、`MON_LORE`、`BOSS_LORE`）。

## 核心設定

- **白塔**：一座兼作書庫與考場的高塔，也就是地牢本身。「大考」在這裡舉行，考上的人成為**燈守**。
- **燈守與燈**：每位燈守守著一盞燈，燈裡存放世界的一部分知識。燈熄滅，那部分知識就被遺忘；被遺忘的東西會變成怪物。
- **那一晚（黑潮／墨潮）**：第七屆大考那晚，出題的人寫下了「**最後一題**」，一道沒有答案的題目。題目寫下的瞬間紙頁破裂，墨水從題目裡湧出，淹沒了塔的下層，形成**深淵**與**黑色的海**。遊戲內不說「墨潮」這個名稱的由來，只用「那一晚」「黑色的雨」「水位在漲」「那一晚的浪」來暗示。
- **空白**：墨的更下面，是什麼都沒有的「空白」，也就是徹底的遺忘。最深處的怪物（無字者、虛空之眼、黑洞魔導師）都來自這裡。
- **魂晶**：倒在塔裡的考生，他們的不甘心結晶而成。玩家用魂晶強化，等於繼承前人的意志（遺物「經驗寶珠」、怪物「水晶魔」「晶化巨像」暗示）。
- **營火**：塔外最後一盞沒熄的燈（「營火餘燼」「最後一盞燈」「守夜人的毯子」）。
- **寵物**：貓（以及其他夥伴）不需要記住任何事，所以墨碰不到牠們（「貓咪茶杯」）。唯一的例外是自己走進墨裡找主人的「影貓」。
- **玩家**：新一屆的考生，可能是那個能答出最後一題的人。永遠不要明說。

## 反覆出現的意象

- 「第七屆」「座號 0」「放榜那天」「考試延期」：第七屆大考沒有結束，也沒有放榜。
- 沒寄出的信、護身符、柚子樹：考生想回家。
- 沙漏與時鐘：那晚之後，時間在塔裡不正常。
- 書、頁、字、句點：被吃掉、被擦掉、被遺忘的知識。

## 新增內容的規則

1. 每件遺物、每隻怪物、每位首領都要有一段 1～2 句的介紹，語氣平靜、略帶憂傷，可以有一點幽默。
2. 只描述物件或生物「是什麼、留下了什麼痕跡」，不解釋世界發生了什麼事。
3. 不要用「墨潮」「最後一題的真相」這類詞直接下結論；「最後一題」可以出現，但不說它的內容。
4. 新的怪物盡量從「考場的物品」「塔裡的人」「被墨改變的動物」「來自空白的東西」四類發想。

# 視光學歷年國考：同題型分組

同一組＝解題邏輯與算法完全相同，只換數字或小改選項（含同一題重考）。換未知數（例如反過來求距離）、多一個步驟（例如先換算焦距或扣工作距離）、換成另一種寫法（正柱鏡）都算不同題型，不放同一組。只收兩題以上的組；沒列出的題目各自是獨立題型。

範圍：視光學科目的歷年國考題（114 大一下第01～09單元、115 大二上視光學二），共 810 題。 分成 141 組、429 題；其餘題目各自是獨立題型。

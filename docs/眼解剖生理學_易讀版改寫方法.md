> 給接手的人（人或 AI）：這份是「怎麼改」的完整說明。進度與接手步驟在專案根目錄 `SESSION_NOTE.md`。

- 「**不需要被學習模式的框架束縛**，不一定要每一個知識後面都接一個練習，也可以**概念的頁數多一點**」。

## 2. 一頁的骨架

```
標題（一件事）
> [!big] 一句話（只看這句也知道這頁要記什麼）
圖（[[img]] 放在一句話後面）
3～5 行短句／::: flow 流程／::: cols 比較
最多一個提示框（[!tip] 記法、[!why] 為什麼、[!warn] 陷阱、[!key] 一定要記、[!note] 補充）
🎯 exam（每一條附出處：「109 師高 15」「113 生普 11」「老師隨堂考 5」）
✏️ demo（需要時：拿一題實際走一遍）
```

- **一頁只講一件事**。舊卡片塞了三件事就拆成三頁。一課 8～14 頁概念很正常。
- **不要重複**：同一句話不要同時出現在 big、提示框、keys、exam。`keys`（📌 重點）只在「補充新的整理」時才寫，大部分頁不寫。
- **句子短**：一行一件事，用條列。不寫「我們來看看…」這類過場。
- **考點全保留**：舊卡片的 body、keys、exam、demo 裡每一個事實與出處都要出現在新版某一頁（可以換位置、換說法）。改完逐條對一次。
- **專有名詞**：第一次出現寫「中文（英文）」；考卷有多種譯名時寫出來（例：內核層＝內顆粒層）。
- **配色**：一課挑 1～3 組「互相對比的東西」，固定顏色，例如中央動脈 `{o:}` 橘／脈絡膜 `{b:}` 藍、交感 `{r:}` 紅／副交感 `{g:}` 綠。文字和自製圖用同一套顏色。

## 3. 可用的排版元件（規格：`docs/格式_學習模式.md` §8.11）

| 寫法 | 效果 |
|---|---|
| `> [!big] 一句話` | 金色大字橫幅 |
| `> [!tip]`／`[!why]`／`[!warn]`／`[!key]`／`[!note]`／`[!exam]` ＋ 自訂標題；下一行起 `> 內容` | 彩色提示框 |
| `::: cols o b` … `\|\|\|` … `:::`（每欄第一行用 `### 標題`；`o b` 是每一欄的顏色，要和文字配色一致） | 並排比較（手機自動直排） |
| `::: flow` 每行一站 `:::` | 箭頭流程 |
| `{o:文字}` 橘、`{b:}` 藍、`{g:}` 綠、`{r:}` 紅、`{p:}` 紫、`{y:}` 金 | 上色 |
| `==文字==` | 螢光標記（少用） |
| `[[img]]`（card body 單獨一行） | 圖片放在這裡 |

課加 `"pace": "free"`：不再要求每張卡後面接 check。

## 4. 不能動的東西

- **檢核題（check）與記憶卡（flash）的題目文字不要改**：id 是題目文字的雜湊，改了使用者的複習盒紀錄會斷。可以移位置。
- **課的 id、`teaches`、`practice`（qids／pick）不要改**，題庫連結靠它們。
- 舊的 `example`、`practice`、`recap.flash` 原樣沿用；`recap.points` 可以重寫成新版重點。
- 每張概念卡都要有 `exam`（`tools/eye115-qa/check.cjs` 會檢查）；複習課（「國考重點複習」）的卡片還要有 `demo`。
- 建置用 `--strict` 要 exit 0；覆蓋檢查若出現「教材沒提到的標籤／孤兒題」，表示新版漏寫了某個考卷用語，**補進教材**，不要改題目。
- 國考出處：題庫題幹的【…】標示在 2xx／3xx 題號可能把驗光生普考標成驗光師（見 CLAUDE.md），出處以舊卡片寫法或原卷 PDF 為準。

## 5. 圖

- 使用者偏好**真實圖片**（標本、切片、眼底照、解剖圖），不要自繪示意圖。可以在開放授權圖上**重新標註**（中文、配色、括號、箭頭）。
- 現有可用的圖：`img/eye-anat-fig/`（已標註）、`img/eye-anat-manual/`（無標籤底圖，點位在 `E:\NEWTEST\eye_work\annot.py` 的 `REG`）。來源與授權寫在 `img_source`。
- 新標註圖寫在 `tools/learn-redo/*_figs.py`（範例 `retina_figs.py`：裁切、加大字、配色括號、標籤框）。字型 `C:/Windows/Fonts/msjhbd.ttc`；標籤字至少 36px（圖會縮小顯示）。標點位要逐張看圖確認，原圖無法確認的不要硬標（例：桿／錐顏色無法確認就合標）。
- 下載新圖要先問使用者。

## 6. 流程（每一課）

> **2026-10-18 使用者更新**：不要每課截一堆圖檢查，快速做過去；**圖片沿用現有的（img/eye-anat-fig/ 已標註圖），不要大量重做**，先把文字處理好。每課只跑 `--strict` 建置；做完幾個單元再跑一次 eye115-qa。下面第 6、7 步改成「偶爾抽查」。


1. 讀舊課：`python -X utf8 -c "import json;…"` 或直接看 JSON；列出所有事實與出處。
2. 查題庫：這課 `teaches` 對應的題目（`content/bank/eye_ans/exam115/`、`quiz/`），確認考點都有教到。
3. 寫腳本 `tools/learn-redo/<unit>_<lesson>.py`（用 `common.py` 的 `Unit`、`pick`、`card`），執行。
4. `python tools/build.py --strict`（exit 0）。
5. 把 `index.html` 的 `?v=N` 加一（只改 JSON 時不用，但改了 JS／CSS 要加）。
6. 截圖檢查：`$env:NODE_PATH='E:\NEWTEST\skull-atlas-3d\node_modules'; node tools/learn-redo/shot.cjs <unitId> <lessonId> <prefix>`（桌機＋390px，輸出 `output/playwright/<prefix>-*.png`）。逐張看：有沒有重複、太長、圖太小、橫向捲動。
7. QA：`node tools/learn-redo/sweep.cjs [unitId…]`（每一步桌機＋390px：語法外露、空白、圖、橫向捲動；最快的整體檢查）；`node tools/eye115-qa/check.cjs`、`node tools/eye115-qa/sweep.cjs`、有圖的話 `node tools/figs-qa/check.cjs`（約 3 分鐘）。
8. 更新 `SESSION_NOTE.md` 的進度表。

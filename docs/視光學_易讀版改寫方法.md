# 視光學易讀版：使用者認可的教材形式

更新：2026-10-18，v117。範圍限視光學二第02單元MSR（10課）、第03單元視野（10課）、第04單元雙眼平衡（7課）。不含第01單元及其他學期；不要因此覆寫眼解剖生理學。

## 寫作順序

使用者認可的是JCC第四版的**概念銜接＋第三版視覺**。前三版的卡點是「小圓、兩方向、兩面差突然冒出來」，不是少一句術語翻譯。

1. **先指具體對象。** 例如看遠方同一顆小燈；說明上下、左右是收攏同束光的兩個方向。不要先丟COLC、主子午線和公式。
2. **再命名。** 小燈在網膜的圓形模糊光斑才叫最小錯亂圓；不是眼球裡的一個圓形器官。縮寫初次出現，連回中文與用途。
3. **再講動作和原因。** 同一片JCC翻轉，正負作用交換，不從上一面累加；先說在改什麼，才說加減多少。
4. **最後才算。** 每個數值附單位與對象；D是鏡片力量、°是方向／視角、20/40是視力，不能混用。
5. 用同一個例子走完；換條件時明說換了什麼。不能上一段談眼睛收光，下一段忽然拿鏡片軸位當同一個方向。

不是把內容變淺。要補足前置橋梁，保留細節、條件與原考題來源。國考題型的特殊說法和通用原理不同時，明確標示脈絡。

## 視覺與節奏

- 一頁一個結論；先金色重點句，再用短表格或兩欄色塊展開。
- 藍：方向／位置；橘：力量／操作量；綠：較清楚／確認；紫：限制／較模糊。不整段染色。
- 每格一件事，列名短；手機盡量2～3欄。必要的數字對照可4欄，但必須看390px實際截圖。
- 先把概念講完再練。`pace: "free"`允許連續概念頁，不需要每個名詞後接題。
- 本次把原卡中的國考重點分到接續考點頁、原示範分到演練頁，減少概念頁下方堆密文；未新增一堆檢核。
- 圖片有明確工作才放：光斑形狀、儀器外形、視野型態、路徑等。不要每頁貼整張講義。圖片可點放大；需圖源與授權。
- 已認可的JCC版面與比喻不要在後續重做成另一套風格。

## 正本與重建

內容正本是 `content/learn/optometry/optom2/optom2-u{2,3,4}-*.json`。每課手寫腳本在 `tools/learn-redo/msr_l*.py`、`vf_l*.py`、`bb_l*.py`；共用 `optometry_common.py`。JCC l4沿用 `optom2_jcc_l4.py` 與兩份HTML互動。

腳本從固定基準 `22cfdff` 取原題、範例、實戰、記憶卡，僅替換指定課。不可重跑舊素材匯入器把成品覆蓋。

```powershell
python -X utf8 tools/learn-redo/msr_l1.py
# 需要哪課才跑哪課；跑完需同步已確認的內容更正
python -X utf8 tools/learn-redo/optometry_corrections.py
python -X utf8 tools/optom2-qa/readability-audit.py
python tools/build.py --strict
$env:NODE_PATH='E:\NEWTEST\skull-atlas-3d\node_modules'
node tools/optom2-qa/readability.cjs
node tools/optom2-qa/jcc-trial.cjs
```

`data/*.js`不能手改。CSS只套這三單元；播放器用data-pack／data-lesson定位。改JS／CSS需加index.html快取版本。所有題庫檔未降級或刪題。

## 完整性與進度

27個課程ID、97個檢核題幹、172張記憶卡正面保留，讓自動進度鍵仍對應；有誤的選項、答案背面與題解同步修正，不以「保留原文」為由繼續教錯。逐欄差異在 `tools/learn-redo/optometry-corrections.json`。

原範例、實戰與考題出處經程式核對；共360筆「每課去重後」出處（跨課可能重複），不代表360道獨立題目。原考點細節逐來源卡對照改寫，程式核對不等於完整醫學審稿。

`optometry-progress.json`逐課記錄；每完成一課，腳本更新session note。未完成驗證時只標「已改寫」，不能直接寫完成。學習中的舊存檔若停在中段，新增頁面後同一頁序未必是原內容；可以回課程開頭重讀。課ID及題目／卡片的進度鍵保留，未清除使用者存檔。

## 核對時發現的問題

| 問題 | 本次處理 |
|---|---|
| MSR講義第9頁20/200散光寫<4.00，前列20/120為4.00 | 實際渲染講義核對，保留原值並標待老師確認，不編造替代數值 |
| 裂孔、鐘面、JCC的精度排序互相矛盾 | 不再用單一粗細階級敘事；保留106生普42的JCC＞裂孔＞鐘面題型 |
| ±0.37與−0.75的算術 | 解釋名目±0.375及取位；不寫0.37×2＝0.75 |
| 0 dB直接等於全盲 | 改為最大刺激；最大刺激也無反應才是該測點絕對暗點，含卡片／題解／筆記一起更正 |
| PD被說成只比自己其他點 | 說明估整體偏移、校正後再與常模比；PD不是時間趨勢 |
| 微視野「沒有學習效應」 | 依研究加條件；更正一題多選的E選項與解說，答案仍ACD |
| 普通稜鏡平衡混入「紅綠無反應者不能做」 | 分清普通兩行模糊比較與稜鏡紅綠版 |
| 所有視野一律單眼／60歲一律免平衡 | 限定本課診斷流程與實際調節能力，不擴大為無例外規則 |
| 對坐小白球「眼前5 cm」定位不明 | 保留爭議說明，不教成球放病人眼前5 cm；採課堂兩人中間的刺激面 |
| Amsler「不能用於糖尿病」 | 不取代糖尿病網膜病變全面篩檢；但黃斑受影響可有方格異常 |
| WHO 0.05／10°與台灣20° | 區分歷年題措辭、矯正條件、低於／以下邊界；台灣20°不是完整法定分級 |

## 測試界限與舊工具注意

原 `tools/optom2-qa/check.cjs` 的「每卡都要exam＋demo」是舊形式約束，不適合本次自由節奏；新驗證用 `readability-audit.py`、`readability.cjs`、`jcc-trial.cjs`。

舊 `tools/learn-redo/sweep.cjs` 只寫localStorage、不reload，可能一直渲染同頁；舊數字不作逐頁驗證證據。本次已補reload與實際頁碼檢查。新版 `readability.cjs` 每課reload，再實際按跳頁色條，逐步核對頁碼、類型、圖片、溢出及判分。

瀏覽器測試使用一次性Edge context，備份／還原該context的localStorage，不使用真人瀏覽器存檔。測試報告在 `output/playwright/optometry-readability-*`。沒有實機iPad、真實初學者理解度或完整醫學審稿認證；自動通過不能代替使用者試讀。

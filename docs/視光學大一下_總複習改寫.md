# 視光學大一下：九堂總複習的易讀版

2026-10-18，v124。沿用[已認可的JCC改寫方法](視光學_易讀版改寫方法.md)，本次僅改114大一下各單元最後的「國考重點複習」，不擴及其他正課。使用者要求逐課完成、品質優先。

## 範圍與概念順序

| 單元 | 課ID | 先建立的具體觀念 |
|---|---|---|
| 01 視力與屈光不正 | l8 | 看清細節的能力和鏡片度數不同，再連接小數、Snellen、MAR、logMAR |
| 02 散光與處方 | l7 | 同一個小亮點，兩個垂直方向未同時對焦，才命名焦線與最小錯亂圓 |
| 03 視網膜檢影入門 | l5 | 看的是瞳孔裡的反光；工作距離和工作鏡先分清，再算毛值／淨值 |
| 04 瞳距與焦度計 | exam-review | 光偏向基底、影像移向頂角，再談Prentice、偏心和雙眼稜鏡 |
| 05 他覺驗光 | exam-review | 淨處方固定，工作距離變時毛值跟著變；分清何時已扣工作鏡 |
| 06 角膜曲率 | exam-review | 曲率半徑越小越陡，才連到K、角膜散光、殘餘散光與地圖 |
| 07 瞳孔反應 | exam-review | 瞳孔是洞、虹膜肌肉使它變大小；先分傳入／傳出，再讀RAPD |
| 08 立體視 | exam-review | 兩眼畫面略有位置差；分辨視差、深度及不同測驗用的眼鏡 |
| 09 調節／集合近點 | exam-review | 水晶體對焦與眼球轉向不同；先定義距離與正負號，再計算 |

第04～09單元的複習課在各自p2檔。p1、其他正課與99名詞沒有另造一堂複習，也未更動。

## 逐課做法

1. 先寫正在看誰、量什麼，再引入中文名、英文與縮寫。不能只把術語刪短。
2. 金色框只放一句主旨；正文用短表格比較。藍／橘分對象，綠／紫分結果與限制，不把整段都上色。
3. 一頁處理一個推理。原國考提醒分到後頁、每頁至多兩則；原示範也另頁保留，避免概念、考點、算式同頁擠滿。
4. 可連續數頁概念，不強制每卡接一題。保留原32題檢核與原範例，不為增加互動而加題。
5. 散光沿用已驗證的「前方焦線→中間圓形光斑→後方另一焦線」三狀態互動，不塞整張講義。圓是屈光度中點的折衷，仍不是清晰點。
6. 最後演練只抽該單元現有國考題本，避免舊p2複習以關鍵字抽到其他單元。

## 完整性與必要更正

固定比對基準：`a72883ca00ed1ba3ecb958c5ab5d89f4f120d5dd`。九堂課ID、原檢核題幹、33張記憶卡正面與原出處保留。其他課與pack欄位（含筆記）逐欄相同；原有考題引用以「每課去重後加總」計304筆，並非304題不同國考題。

共13處既有文字的必要更正列於`tools/learn-redo/s114-review-corrections.json`（含欄位、前後文）：

| 舊文容易誤讀之處 | 改法 |
|---|---|
| 0.5全對、再讀0.4行，直接每字扣0.02 | 明寫這是五字、每行0.1的logMAR表；不是小數視力相減 |
| 小數／MAR／logMAR數字連寫，量綱不清 | 每個結果寫清所屬視力表示法 |
| 針孔無改善就一定是疾病 | 作為線索，不能單憑針孔唯一判斷 |
| 視覺皮質受損一概寫失明 | 限定雙側廣泛受損；光反射通道完好時仍可保留 |
| 遠點在眼後卻和近視符號混算 | 全課統一R＝剩餘屈光誤差，近視負、遠視正；A＝1/d＋R |
| NPC15 cm即確診集合不足 | 是線索，仍須眼位、融像、症狀等檢查 |
| 1.3375直接叫真實角膜折射率 | 說明它是K換算的假設／等效角膜指數 |

另在正文補足：順逆動不能只比未標方向的遠點距離；Lang使用離散視差版本；Frisby須區分標準距離與設計的變距測法；Hofstetter是參考值；同軸殘餘散光簡算不能套所有軸位。原題選項與答案未任意改動。

## 重跑與驗證

正本為`content/learn/optometry/semester114/`內九個檔案。逐課手寫腳本為`tools/learn-redo/s114_review_01.py`～`09.py`；共用程式取固定基準的原題，僅覆寫指定最後一課，並保留各檔原縮排。不要用舊匯入器重建整個學期。

重跑指定課後，依序執行：

```powershell
python tools/learn-redo/s114_review_corrections.py
python tools/build.py --strict
python tools/learn-redo/s114_review_audit.py
$env:NODE_PATH='E:\NEWTEST\skull-atlas-3d\node_modules'
node tools/s114-review-qa/check.cjs
```

`s114_review_style.py`只把已認可表格樣式擴到九堂複習，不改其他大一下正課；快取v124。沒有更改播放器JS或存檔格式。新增前置頁使原進行中頁序可能不同，可回課頭重讀，未清除使用者紀錄。

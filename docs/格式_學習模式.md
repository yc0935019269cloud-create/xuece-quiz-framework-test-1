# 學習模式格式規格 `xd-learn/1`

> 一個 **單元（pack）** 就是一個 JSON 檔，放在 `content/learn/<科目id>/<單元id>.json`，執行 `python tools/build.py` 後會編進 `data/learn.js`，遊戲裡的「📘 學習模式」就會出現。

---

## 1. 資料流

```
講義／PDF／筆記
   │  （AI 對話，用 docs/prompts/01_素材轉學習模式.md）
   ▼
content/learn/bio/bio-cell.json      ← 一個單元一個檔（人看得懂、可手改）
   │  python tools/build.py          ← 檢查格式、節奏、題庫題號；產生穩定 id
   ▼
data/learn.js（window.LEARN）       ← 自動產生，不要手改
   │
   ▼
js/learn.js（LEARN_UI）             ← 課程列表、播放器、複習、筆記
```

- `python tools/build.py --index`：輸出 `content/_index/<科目>.tsv`（題號、題型、標籤、題幹與詳解開頭），給 AI 挑選要連結的題庫題目。
- `--check` 只檢查不輸出；`--strict` 連「節奏警告」也當成失敗。
- 檔名以 `_` 開頭的 JSON 不會被編入（可放範本、草稿）。
- 有錯誤的單元會被跳過，其他單元照常輸出。

## 2. 固定學習節奏（每一課都一樣）

```
導入 intro → ( 概念 card → 檢核 check ×1~2 ) × 2~4 → 範例 example → 實戰 practice → 回顧 recap
```

| 步驟 | 用途 | 規則 |
|---|---|---|
| `intro` | 情境、為什麼要學 | 每課第一步 |
| `card` | 一次只講**一個**觀念 | 後面**必須緊接** `check`；900 字內 |
| `check` | 剛學的馬上練 | 答錯先給 `hint` 再試一次；再錯就揭曉並收進複習盒 |
| `example` | 範例逐步拆解 | 步驟一次揭露一步 |
| `practice` | 題庫題目＋自編題 | 題庫題目會記錄到作答統計與錯題本 |
| `recap` | 重點整理＋記憶卡 | 每課最後一步 |

一課建議 8～18 步（10～20 分鐘）、概念卡 2～4 張。違反時 build 會出現「節奏」警告，但仍可輸出。

## 3. 單元（pack）欄位

```jsonc
{
  "schema": "xd-learn/1",
  "id": "bio-cell",              // 必填，全域唯一，小寫英數與 -；建議「科目-主題」
  "subject": "bio",              // 必填：content/project.json 裡登記的科目 id
  "unit": "機率",                 // 必填：大單元名稱（課程列表依此分組）
  "title": "條件機率與獨立事件",   // 必填
  "desc": "一句話簡介",
  "level": 2,                    // 1 基礎｜2 標準｜3 進階
  "minutes": 30,                 // 預估總時間
  "order": 10,                   // 同科目內排序（小的在前）
  "source": "資料來源說明",
  "tags": ["條件機率"],
  "lessons": [ /* 見下 */ ]
}
```

## 4. 課（lesson）欄位

```jsonc
{
  "id": "l1",                     // 必填，單元內唯一，小寫英數與 -；上線後不要改（進度靠它對應）
  "title": "條件機率：縮小樣本空間",
  "goals": ["學完能……", "……"],   // 1~3 條，顯示在導入頁
  "steps": [ /* 見下 */ ]
}
```

## 5. 步驟（step）欄位

> **所有文字欄位都支援簡易 Markdown**（`**粗體**`、`` `行內碼` ``、清單 `- `、表格 `| |`、引用 `>`、程式碼區塊 ```` ``` ````）。
> 長文字可以寫成**字串陣列**，每個元素是一行（build 時會用換行接起來），比在 JSON 裡寫 `\n` 好讀。

### `intro`
```json
{ "type": "intro", "title": "已知一個消息，機率就變了", "body": ["第一行", "", "- 清單"] }
```

### `card`
```jsonc
{
  "type": "card",
  "title": "條件機率的定義",           // 必填
  "body": ["……"],                     // 必填
  "keys": ["重點一", "重點二"],        // 顯示成「📌 重點」框
  "tip": "老師小叮嚀（寵物說）",
  "img": "img/learn/bio-cell/membrane.png",   // 選填，路徑以框架根目錄為準
  "flash": { "front": "問題面", "back": "答案面" }  // 選填：完成本課後進入複習盒
}
```

### `check`（也用在 `practice.checks` 裡，此時不寫 `type`）
共同欄位：`kind`、`q`（題目）、`answer`、`hint`（第一次答錯時顯示）、`explain`（作答後的解說）。

| kind | 需要的欄位 | `answer` 格式 |
|---|---|---|
| `single` 單選 | `choices`（2~8 個） | 整數，**0 = 第一個選項** |
| `multi` 多選 | `choices` | 整數陣列，如 `[0, 2]` |
| `tf` 是非 | — | `true` / `false` |
| `fill` 填答 | — | 字串或字串陣列（所有可接受寫法）。比對時忽略空白、全形半形、大小寫；**兩邊都是數字或分數時比數值**（`10/18` 與 `5/9` 視為相同；但 `0.556` ≠ `5/9`，要接受近似值就把寫法都列進陣列） |
| `order` 排序 | `items`（**依正確順序**寫，至少 3 項；遊戲會自動打亂） | 不需要 |
| `self` 自評 | — | 參考答案文字（學生看完自評對錯），用在申論、翻譯、寫作 |

```json
{ "type": "check", "kind": "single", "q": "……", "choices": ["1/2", "1/3", "2/3"], "answer": 2,
  "hint": "已知是偶數，新的樣本空間只剩 {2, 4, 6}。", "explain": "……所以是 **2/3**。" }
```

### `example`
```jsonc
{
  "type": "example",
  "title": "已知結果，回推原因",
  "problem": "題目敘述（Markdown）",
  "steps": ["第 1 步……", "第 2 步……"],   // 每個元素是一步，逐步揭露；元素也可以是字串陣列
  "answer": "最後結論"
}
```

### `practice`
三種來源可以混用，至少要有一種；遊戲依「qids → pick → checks」順序出題。
```jsonc
{
  "type": "practice",
  "title": "實戰：條件機率",
  "qids": ["bio-ch1-3", "bio-ch1-7"],     // 指定題庫題號（見 content/_index/*.tsv）
  "pick": { "match": ["細胞膜"], "subjects": ["bio"], "n": 2 },  // 依關鍵字從題庫隨機抽（比對標籤與詳解，未做過的優先）
  "checks": [ { "kind": "fill", "q": "……", "answer": ["15/19"], "hint": "……", "explain": "……" } ]  // 自編題
}
```
建議每個 `practice` 放 2~4 題，其中至少 1 題題庫題目（若題庫有相關題目）。

### `recap`
```json
{ "type": "recap", "points": ["重點 1", "重點 2"], "flash": [{ "front": "……", "back": "……" }], "next": "下一課預告（選填）" }
```

## 6. 寫作規範

- **數學式用純文字＋Unicode**（遊戲離線、沒有 LaTeX）：`x²`、`x³`、`xⁿ`、`a₁`、`√2`、`∛`、`π`、`∩ ∪ ⊂ ∈`、`≤ ≥ ≠ ≈`、`×  ÷`、`→ ⇒ ⇔`、`Σ`、`∞`、`°`、`θ`、`Δ`、`log₂`；分數寫 `a/b`；重要公式放在 ```` ``` ```` 程式碼區塊（等寬、醒目）。
- 化學式用下標字元：`H₂O`、`CO₂`、`SO₄²⁻`、`Fe³⁺`、`⇌`。
- 一張概念卡只講一件事；先講「是什麼」再講「怎麼用」，最後一句點出易錯處。
- `hint` 要**引導思路**、不要直接給答案；`explain` 要說明**為什麼**，錯誤選項的陷阱也點一下。
- 誘答選項要來自真實常見錯誤（例如「放回」和「不放回」搞混）。
- 用學習者熟悉的用語（例如台灣課綱名詞、該證照的官方用語）。
- **不要把原講義整段照抄**：改寫、重組成卡片。

## 7. 進度與複習（給開發者）

- 存檔鍵 `qg_<專案id>_learn`：`les["單元id/課id"] = { i 目前步驟, done 完成次數, best 最佳星數, last, run{ok,n,sub,pk,t0} }`、`rev[項目id] = { box 1~6, due 到期時間, n, w }`、`stat`。
- 項目 id 由 build 依「單元/課/題目文字」雜湊產生（`c` 開頭＝檢核題、`f` 開頭＝記憶卡）；**改題目文字會變成新項目**，舊複習紀錄自動忽略。
- 複習盒間隔 `BOX_DAYS = [0, 1, 2, 4, 7, 15, 30]` 天：答對升一盒、答錯回第 1 盒。檢核題第一次答錯立刻進盒（當天可複習）；記憶卡在完成該課後隔天到期。
- 星數＝第一次就答對的比例（≥90% ★★★、≥70% ★★、其他 ★）。首次完成：魂晶 3＋星×2、帳號經驗 25、寵物經驗 12；重溫只補更高星數的差額。
- 實戰中的題庫題目走 `QV.render` 與 `Store.record`，會計入每日目標、題目統計與錯題本。
- 單元頁的「帶著這些題目去遠征」用該單元所有連結題目開一場 `mode: 'list'` 短遠征。

## 8. 新增功能（v2）

### 8.1 分類階層 `path`
單元可以放在多層分類裡（年級、學期、冊、章、節…），課程列表會顯示成可收合的樹：

```json
"path": ["高二", "上學期", "第3章 光的反射與折射"]
```
- 最多 5 層，由大到小；同一系列的單元每層文字要一模一樣。
- 第一層和科目名稱相同時會自動省略（不會重複顯示）。
- 沒有 `path` 時用 `unit` 當成一層。`unit` 若和 `path` 最後一層不同，會接在最後。

### 8.2 檢核題答案可以寫字母
`single`／`multi` 的 `answer` 除了 0 起算的數字，也可以寫字母：`"B"`、`"AC"`（和題庫一致，AI 比較不會出錯）。

### 8.3 圖解 `diagram`（看圖認構造）
```json
{ "type": "diagram", "title": "眼球水平切面", "body": "說明", "img": "img/anat-eyeball/section.png",
  "source": "作者, Wikimedia Commons, CC BY-SA 4.0", "mode": "both",
  "points": [ { "name": "角膜 Cornea", "desc": "最前方透明的纖維層", "x": 12.5, "y": 50 },
              { "name": "水晶體 Lens", "desc": "……", "x": null, "y": null } ] }
```
- `x`、`y`：標記點位置，佔圖片寬、高的百分比（0～100，左上角 0,0）。
- 座標是 `null`（AI 看不到圖時）：第一次打開時會請使用者依序在圖上點出位置；任何時候都可以按「📍 調整標記」修正。自訂位置存在 `learn` 存檔的 `pins`。
- `mode`：`both`（先探索、再做辨識測驗，預設）、`explore`（只探索）、`quiz`（直接測驗）。辨識測驗最多 5 題，計入星數與戰鬥。
- 測驗用的圖最好沒有印上名稱標籤。

### 8.4 互動 `interactive`（模擬／動畫）
```json
{ "type": "interactive", "title": "光學桌", "body": "說明", "task": "具體任務", "height": 460,
  "html": ["<!doctype html><html>…", "<script>…</script></html>"] }
```
- 在 `sandbox="allow-scripts"` 的 iframe 裡執行（不能存取遊戲、存檔、網路）；必須完全內嵌，不可載入外部檔案。
- `html` 可為字串或字串陣列；不是完整 HTML 文件時會自動包上基本樣式。
- 使用者可按「⛶ 放大」「↻ 重新開始」。看到互動內容會累積 1 點知識能量。

### 8.5 卡片圖片
`card.img` 可以是字串或字串陣列（多張圖），圖片來源寫在 `img_source`。

### 8.6 學習戰鬥
- 每一段（以 intro／card／example／interactive／practice／recap 分段）若含檢核題或圖解測驗，就出現一隻怪物，HP＝10 × 題數；名字前綴用科目的 `words`。
- 讀 card、玩 interactive：知識能量 +1（最多 3，同一步只算一次）。
- 第一次就答對：傷害 10（有能量時消耗 1 點變暴擊 15）；提示後才答對：傷害 5；每次答錯：扣 1 ❤（5 顆），扣光時夥伴扶起（記一次倒下，不影響學習）。
- practice 出現精英怪；整課最後有課末魔王（從本課檢核題抽 3～5 題，不給提示；首領依科目主題）。
- 擊敗怪物：魂晶 +1（精英 +2），魔王 +4，並記入怪物圖鑑。右上角可切換「🕊 平靜模式」（存在 `cfg.battle`）。

### 8.7 整包 `xd-bundle/1`
一個檔案可以同時放科目、題本、單元與圖片（AI 輸出、導入頁「下載」都用這個格式）：
```json
{ "schema": "xd-bundle/1", "subjects": [ … ], "sets": [ xd-bank/1 … ], "packs": [ xd-learn/1 … ], "images": { "路徑": "data:image/png;base64,…" } }
```
- 用「📥 導入素材」導入，或放進 `content/` 由 `tools/build.py` 編入（內嵌圖片會寫成檔案）。

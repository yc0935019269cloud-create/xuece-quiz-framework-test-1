# 國考題 PDF 解析器

`parse_exam.py`：把 `E:\學習\驗光師國考題\<驗光師|驗光生>\<科目>\*.pdf` 解析成 `{題號, 題幹, 四個選項, 標準答案}`，輸出 `exams.json`（先改檔案頂端的輸出路徑）。答案取自每份 PDF 最後一頁的標準答案表；答案標 `#` 的題目有更正答案，要看備註頁（解析結果為 `None`，需人工處理）。

注意：選項若含換行，PyMuPDF 可能把前一行數字併到題幹尾端（例如「30°」被併進題幹、選項變成「度 60」），挑題後要逐題對照原卷。114 年驗光生普考只有答案頁（沒有題目檔）。

已匯入的題本與詳解在 `content/bank/optometry/optom2/exam/`，內容正本是 content/，不要用生成流程覆蓋。
